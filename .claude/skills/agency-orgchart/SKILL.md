# 관계부서 조직도 - `10_Ai/10_업무매뉴얼/1_사무소_자료/관계부서/`

## 0 · 사용자가 정한 것 (2026-10-02)

> 📄 *"주로사용하는 관계부서의 홈페이지와 조직도도 저장하려고 해"*
> 📄 *"전화번호 · 2. 건축허가 등의 동의 착공신고 완공 검사에 관한 사항(대치동,수서동,자곡동) · **이런 내용만 매치하면 될꺼같아**"*
> 📄 *"구청 조직도 분석에서 **건축관련 분야들을 다 가져와야해** · 건축과 / 도시계획 / 주택 / 도로 / + 협의 - 장애인 < 이건 장애인 센터 전화번호를 찾아서 넣어야하고 + 협의 - 소방 < 이건 소방서로 대체하고 있고"*
> 📄 *"조직도는 계속 추가될꺼니까, 뭔가 스킬 가이드로 잘 정리해두면 될꺼같아"*

- **꼴** - 절 하나 = 분야 하나. 표는 「전화 | 맡은 일 | 팀」 뿐이고 맡은 일은 **조직도 글자 그대로 한 줄**이다. 그 과 전체 표는 그 밑에 접어 둔다.
  첫 판은 동 14줄 표 + 팀마다 펼친 담당업무 + 다른 팀 절까지 실었다가 *"이런 내용만"* 으로 줄였다 - **많이 싣지 않는다.**
- **구청** - 건축 일에 걸리는 분야를 **다** 가져온다. 사용자가 부른 분야 밖에서 낱말에 걸린 과는 표로 보이고 더할지 묻는다(강남구청은 여섯을 다 더했다).
- **협의 - 장애인** - 그 구의 장애인 센터(편의증진기술지원센터) 전화를 **찾아서** 넣는다. 구청 홈페이지의 장애인복지 안내 화면에 있다.
- **협의 - 소방** - 구청 덩이에는 고리 한 줄만 두고 같은 장의 소방서 덩이(`#소방서-인허가`)로 넘긴다.

## 0-1 · 한 구 = 한 장 (2026-10-06 사용자)

> 📄 *"강남소방서 / 강남구청 이렇게 두가지로 구분되어있는데 **강남구 - 한페이지로 통일하자** (종로구도 마찬가지)"*
> 📄 *"그 안에, **구청 / 소방서 / 장애인센터** 등 여러가지 정보를 다 모아야할꺼같아 · 그래서 **페이지 안에서 기관별로 구분**되도록"*

- 장은 **구마다 하나** - `강남구.html` · `종로구.html`. 그 안에 기관마다 한 덩이(`<section id="구청" class="기관">` · `소방서` · `장애인센터`), 기관 머리에 받은 날ㆍ원본, 장 머리에 기관 고리 줄.
- 기관의 절은 그 덩이 안에 `<section id="<기관>-<절>">` (h3) - 오른쪽 「이 장의 절」 에는 기관(h2)만 나온다.
- **장애인 센터는 기관 하나다** - 구청 「협의 - 장애인편의시설」 절에는 구청 담당(장애인복지과ㆍ사회복지과)만 두고 센터 덩이로 고리.
- 옛 기관별 장(`강남구청.html` …)은 정본을 `옮김: {장, 기관, 날}` 한 줄로 바꿔, 옛 고리가 새 장의 그 기관으로 넘어가는 장만 뽑는다. 지우는 것은 사용자가 정한다.
- 새 기관(보건소 · 교육청 …)도 그 구 장의 `기관:` 에 하나 더한다 - 새 장을 짓지 않는다.

## 1 · 차례 - 관계부서 하나를 더할 때

```
① 조직도 화면을 받아 본다        글자가 바로 오나 · 스크립트로 그리는 화면인가 (2절)
② 정본 yaml 을 짓는다            1_사무소_자료/관계부서/<구>.yaml 의 기관: 에 하나 더한다 (새 구면 그 장을 짓는다) - 기관ㆍ받기 칸만 먼저 (3절)
③ 받는다                        관계부서.py --받기 "<정본>" --기관 <이름표>   부서마다 1초 쉰다 · 구청 81부서면 2분 → 먼저 알린다
④ 어느 과에 있는지 센다          관계부서.py --낱말 "<정본>" 건축 인허가 점용 …   ★받은 부서 전체에서
                                관계부서.py --낱말 "<정본>" 인허가 --과 건축과    그 과의 줄을 본다
⑤ 정본에 절을 적는다             분야마다 찾기 규칙 (낱말은 ④에서 본 글자 그대로)
⑥ 뽑는다                        관계부서.py --뽑기 "<정본>"      찾기 표마다 줄 수를 찍는다 · 0 줄이면 멈춘다
⑦ 잰다                          관계부서.py --검사 "<정본>"      「탈 0」
⑧ 목록.js 에 한 줄 (새 구일 때만)  사무소 자료 › 관계부서 아래 { 이름: '<구>', 주소 }  → 인용.py --검사 <장>
⑨ 탐색기로 장을 연다              사용자가 보고 뺄 것ㆍ더할 것을 짚는다
```

사용자가 부르지 않은 과가 ④에서 걸리면 **표로 보이고 더할지 묻는다**(`CLAUDE.md` §2). 혼자 더하지도, 말없이 빼지도 않는다.

## 2 · 받는 길 - 사이트마다 다르다

| 꼴 | 어느 사이트 | 정본 `받기:` | 사본 |
|---|---|---|---|
| `서울시조직도` | 서울 소방서 25곳 · 서울시 부서 (`org.seoul.go.kr`) | `부서코드: 6110582` | `부서나무.json` + `<코드>_<부서>.json` |
| `강남구청` | 강남구청 홈페이지의 「조직도」 화면 (주소는 `강남구.yaml` 의 구청 받기 칸) | `주소: …find.do?mid=…` | `<과>_직원현황.html` |
| `종로구청` | 종로구청 홈페이지의 「조직도」 화면 → 과마다 「부서안내」 (2026-10-06) | `주소: …Main.do?menuId=1917…` | `<과>_부서안내.html` |

**서울 소방서** - 홈페이지(`fire.seoul.go.kr/station/<서>/intro_organization_chart`)는 스크립트로 그리는 화면이라 그냥 받으면 글자가 없다.
속에 서울시 조직도를 끼워 보여 준다. 부서 코드만 알면 된다 :

```bash
python "10_Ai/10_업무매뉴얼/system_도구/관계부서.py" --코드찾기 "https://fire.seoul.go.kr/station/<서>/intro_organization_chart"
```

**다른 구청** - 사이트가 구마다 다르다. 받는 길이 없으면 **먼저 짓는다** :

```
⑴ 조직도 화면을 그냥 받아 과 이름이 글자로 오는지 본다
⑵ 과를 눌렀을 때 부르는 주소를 화면 스크립트에서 찾는다        강남구청은 ajaxRequest('3220175') → /dept/user/ajaxDept.do · 종로구청은 과 고리가 바로 화면(deptGuidance.do?deptId=…)
   ★주석(<!-- -->) 속 고리는 걷어 내고 센다 - 화면에 안 보이는 옛 고리다 (종로구청 둘 - 하나는 빈 화면)
⑶ 글자가 안 오면 브라우저로 그려 본다(끼운 틀 주소)             서울 소방서가 그랬다
⑷ 관계부서.py 에 읽기_○○ · 받기_○○ 둘을 더하고 읽기꼴ㆍ받기꼴 표에 올린다   자가검사에 그 꼴 한 칸
```

로그인이 필요한 화면이면 `web-access`. 부서마다 **1초 쉬고** 받는다 - 관공서 사이트다.

## 3 · 정본 yaml

구 장 (2026-10-06 - 지금 쓰는 꼴) - `강남구.yaml` · `종로구.yaml` :

```yaml
장:
  이름: 강남구                   # 장 파일 이름
  작은글: 구청 · 소방서 · 장애인 센터
  머리글: 강남구의 관계 기관을 한 장에 모았다 - …
기관:
- 이름: 강남구청                 # 사본 폴더 이름 (원본/관계부서/강남구청/)
  이름표: 구청                   # 장 안의 고리 #구청 · 절 고리는 #구청-<절 이름표>
  줄임: 강남구청                 # 머리의 기관 고리 줄에 보이는 이름
  작은글: … · 원본글: … · 덧글: … · 팀칸: true
  받기: {꼴: 강남구청, 주소: …, 더: [...]}
  절: [...]                      # 아래 옛 꼴의 절과 같다
  검사: {...}                    # 그 기관의 받은 자료에 댄다
- 이름: 강남소방서 …
- 이름: 강남구장애인 편의증진기술지원센터
  이름표: 장애인센터
  사본: 강남구청                 # 받기 칸이 없는 기관 - 확인한 화면이 있는 기관 폴더를 같이 본다
  절: [...]
이력: [...]
```

옛 기관별 정본 → `옮김: {장: 강남구, 기관: 구청, 날: 2026-10-06}` 한 줄 (옛 고리를 넘기는 장만 뽑는다).

기관 하나짜리 옛 꼴도 도구가 그대로 뽑는다 :

```yaml
장:
  이름: 강남구청                 # 장 파일 이름ㆍ사본 폴더 이름
  작은글: 건축과 · 도시계획 · …
  원본글: 강남구청 홈페이지 「강남소개 › 조직안내 › 조직도」 의 부서별 직원현황
  덧글: 그 화면에는 이름이 없다     # 원본이 원래 그런 것
  팀칸: true                     # 표에 「팀」 칸 (과가 여럿이면 켠다)
받기:
  꼴: 강남구청
  주소: https://…
  더: [{이름: 장애인복지_안내화면, 주소: https://…}]     # 조직도 밖에서 확인한 화면도 사본으로
절:
- 제목: 건축과 - 동별 인ㆍ허가
  이름표: 건축과
  몸:
  - 찾기: {과: 건축과, 무늬: '인\s*[ㆍ・·.]?\s*허가', 그리고: [동]}
  - 전체: 건축과                  # 접어 둔 그 과 전체 표
검사:
  없어야: [{부서: [...], 낱말: [...], 까닭: …}]          # 「그 부서에는 담당이 없다」 고 장에 적었으면
  있어야글: [{파일: 장애인복지_안내화면.html, 글: [...]}]   # 손으로 적은 전화ㆍ주소가 그 화면에 있나
이력:
- [2026-10-02, 첫 판 - …]
```

몸에 쓰는 것 - `찾기`(과 · 낱말 또는 무늬 · 그리고 · 팀 · 자르기) · `전체` · `소제목` · `글`(「[[글|주소]]」 만 고리) · `표`(머리 · 글 · 주소 · 덧) · `나무`(서울시 조직도의 과ㆍ팀 표).
본보기 - `강남구.yaml`(기관 3 · 구청 절 15 · 소방서 절 3 · 센터 절 1) · `종로구.yaml`(기관 3).

종로구청(2026-10-06)은 도로점용 허가가 재무과 보상팀, 주거환경개선구역 안 건축인허가가 주택관리과, 위반건축물이 주택관리과 건축물정비팀, 지구단위계획이 건축과에 있었다 - 분야로 찾고 과 이름으로 찾지 않는다. 줄이 없는 분야는 절을 두지 않는다.

## 5 · 틀리기 쉬운 자리

**「그 과에 없다」 는 전체에서 세고 말한다.** 수서119안전센터에 인허가 담당이 있는지 물으셨을 때 센터 31자리만이 아니라 45부서 356자리에서 세었다 - 「건축허가」 와 「착공신고」 가 함께 든 자리는 예방팀 지도관 넷뿐이었다. 「없다」 고 장에 적으면 정본 `검사: 없어야:` 에 박는다(조직이 바뀌어 생기면 검사가 잡는다).

**맡은 일 한 줄은 딸린 줄까지다.** 조직도는 「○ 장애인 편의시설 설치 시 적용의 완화」 다음 줄에 「(논현동, 도곡동, 수서동)」 을 적는다. 낱말이 든 줄만 뽑으면 **동이 떨어져 나간다.** 도구가 맨 윗줄의 머리 기호(○ · - · 「1.」)로 시작하지 않는 줄을 앞 줄에 잇는다. 서울시 조직도는 딸린 줄이 길어 `자르기: 괄호닫힘`(낱말이 든 줄부터 괄호가 닫히는 줄까지)을 쓴다.

**가운뎃점이 섞여 있다.** 「인ㆍ허가」 「인・허가」 「인.허가」 가 한 과 안에 같이 나온다 - 낱말 하나로 세면 빠진다. 무늬(`인\s*[ㆍ・·.]?\s*허가`)로 적는다.

**이름은 안 나오는 사이트가 많다.** 강남구청은 소속ㆍ직위ㆍ전화ㆍ업무만, 서울시 조직도는 과장ㆍ팀장ㆍ센터장만 이름을 보여 준다. 없는 이름을 다른 데서 끌어다 적지 않는다(일정관리에 적힌 이름은 「일정관리 기록」 이라고 밝혀 적는다).

**원본에 낡은 글이 섞여 있다.** 강남소방서 검사지도1팀장 줄에 「수서119안전센터 업무총괄」 이 남아 있었다. 고쳐 적지 않고 **받은 날**을 장 머리에 둔다.

**맞대는 잣대는 짓는 길과 다른 길로.** `--검사` 는 뽑힌 장(html)을 다시 읽어 표의 글이 **그 전화의 원본 줄** 안에 있는지 본다 - 남의 전화에 붙은 줄을 잡는다. 원본 json 의 글자에 그대로 대면 두 줄로 끊긴 줄이 「없다」 로 나온다(json 을 풀어 읽은 값에 댄다).

**셸 인라인 명령으로 스크립트ㆍ정본을 고치지 않는다.** 역슬래시가 줄어 바꿔치기가 빗나간다(2026-10-02 한 번 · 바꿀 글이 0번 나와 멈췄다). 편집 도구로 고친다.
