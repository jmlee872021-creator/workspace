## 축 — **고쳐 달라고 해도 먼저 잰다**

2026-09-09 에 사용자가 *"페이지번호가 중복된 것들이 있을 거야, 다시 정렬해줘"* 라고 했다.
재 보니 **겹친 번호가 하나도 없었다** — 59장 중 46장에 번호가 있고 오프셋이 **전부 −1** 이었다.
번호 없는 13장은 **표지 3ㆍ간지 9ㆍ「감사합니다」 1** 로, 일부러 비운 것이었다.

⇒ **`--번호` 로 먼저 재고, 안 고쳐도 되면 안 고친다.** 그리고 **그렇다고 말한다.**

★ **그러나 2026-09-30 에는 진짜로 어긋나 있었다** — 「먼저 잰다」는 「늘 멀쩡하다」가 아니다.
  서초동 1714-7 해체계획서(210장) — **자동 필드 0 · 손 숫자 189** 라 장을 더할 때마다 뒤가 통째로 밀렸다.
  겹친 번호 **3**(82ㆍ116ㆍ142 · 116 은 여섯 장) · 어긋난 장 **89 / 189** · 오프셋이 −1(99장)과 −6(78장)으로 **구간마다 달랐다**.
  ⇒ 가른 것은 **「자동 필드냐 손 숫자냐」 하나**다. 필드면 못 겹치고, 손 숫자면 장을 넣을 때마다 밀린다.
```
① --번호 --맞추기 --정말     손 숫자를 규칙에 맞게 다시 쓴다 (90장)
② --번호 --필드로 --정말     그 다음에 자동 필드로 바꾼다 (189개)
   ⚠ 차례를 지킨다 — 어긋난 채로 --필드로 하면 「보이는 번호가 달라진다」로 도구가 멈춘다
```
  두 걸음 뒤 — 겹침 0 · 어긋남 0 · 자동 필드 189 · 손 숫자 0 · 슬라이드 210장ㆍ글 도형 4,120개 그대로.
  ★ 고치면 **찍힌 쪽 = 슬라이드 − 1** 로 전 구간이 하나가 된다. 그 전에는 앞쪽 +1 · 뒤쪽 +6 이라
    **쪽으로 적어 둔 검토 목록이 구간마다 다르게 어긋나 있었다** — 고친 뒤 그 목록의 쪽도 함께 맞춘다.
  ⚠ **파일이 파워포인트에 열려 있으면 먼저 닫게 한다** — 도구가 고친 뒤 사용자가 저장하면 덮어쓴다.

## 열려 있는 파워포인트를 읽는다 — COM (2026-09-30)

파일을 안 닫고 **지금 화면의 문서**를 읽는다. 사용자가 고치는 중에 쪽ㆍ제목을 확인할 때 쓴다.
```python
app = win32com.client.GetActiveObject('PowerPoint.Application')
p = app.Presentations.Item(1)      # Name · Slides.Count · Saved · app.ActiveWindow.View.Slide.SlideIndex
sh.HasTextFrame / sh.TextFrame.TextRange.Text  ·  sh.HasTable → Table.Cell(r,c)
p.Slides.Item(i).Export(파일, 'PNG', 1600, 1131)      슬라이드 한 장을 그림으로
```
- ⚠ **205장 전수 훑기에 103초** — 칸마다 왕복이라 느리다. 낱말 찾기는 **PDF 로 뽑아 읽는 쪽이 훨씬 빠르다**.
- ⚠ **`Quit()` 을 부르지 않는다** — 사용자 창이 닫힌다. 읽기만 하고 그대로 둔다.
- 어떤 것이 **파워포인트 도형인지 그림 속인지**를 가려 준다 — `Shapes` 에 없으면 그림(Picture) 안이라 ppt 로는 못 고친다(2026-09-30 「초록 박스」 → 통합도면 dwg 를 봐야 했다).

2026-09-11 에 **같은 말을 또** 받았고(5장을 더한 뒤 64장) **또 겹침 0** 이었다. 까닭이 드러났다 —
```
쪽번호가 ★자동 슬라이드번호 필드(a:fld type="slidenum")면 장을 넣고 빼도 ★겹칠 수 없다
겹칠 수 있는 것은 ★손으로 친 숫자뿐이다 → --번호 가 「필드 N · 손 숫자 M」 을 갈라 보인다
손 숫자가 있으면 --필드로 로 바꾼다 (보이는 번호가 달라지는 장이 있으면 도구가 멈춘다)
시작번호 firstSlideNum="0" → 필드는 「순번 − 1」 을 보인다 (표지를 안 센다)
★ 표지를 1쪽으로 세는(+0) 문서인데 시작번호가 0 이면 --필드로 가 멈춘다 → --시작번호 1 (2026-09-30 서초동 _02)

```

## 틀리기 쉬운 자리

| 자리 | 무엇 |
|---|---|
| **그룹 안** | `slide.shapes` 는 그룹 안으로 **안 들어간다.** 쪽번호가 그룹 안이면 **거짓 0** 이 난다. `도형들()` 이 편다 |
| **그룹 좌표** | 그룹 안 도형의 좌표는 **그룹의 자식 좌표계(chOff·chExt)** 다. 그룹 위치를 그냥 더하면 **두 번 더한다** — 2026-09-11 에 아래 탭이 y0.94 인데 **y1.88(판 밖)** 로 찍혔다. `그룹변환()` 이 옮긴다 |
| **오프셋** | `번호 ＝ 순번` 이라고 **넘겨짚지 않는다.** 표지를 안 세면 −1 이다. 도구가 **세어서** 고르고, 다르면 사람이 `--오프셋` 으로 준다 |
| **빈 장** | 번호 없는 장은 **빠뜨린 것이 아니다.** 도구는 **새로 안 넣는다** — 넣을지는 사람이 정한다(지침 ⓖ) |
| **run 쪼개짐** | 글자를 갈 때 `text_frame` 을 통째로 넣으면 **꼴이 날아간다.** run 단위로 간다. run 이 쪼개져 못 갈면 **시끄럽게 끝난다** |
| **되돌림** | 쓰기 **전에** `10_Ai/6_PPTX편집/system_되돌림/` 에 사본, 쓴 **뒤에** 다시 읽어 슬라이드 수ㆍ도형 수ㆍ번호를 맞댄다 |
| **남의 폴더** | 원본은 **있던 자리에서** 고친다. 그 폴더에 `.되돌림` 같은 것을 **흘리지 않는다** |
