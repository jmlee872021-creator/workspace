# ⚠⚠ 갈래마다 **부르는 열쇠가 다르다** — 이게 이 API 의 가장 큰 함정

```
eflaw   법령       ID=법령ID            ← MST= 만 주면 안 열린다
admrul  행정규칙    ID=행정규칙일련번호
expc    해석례      ID=해석례일련번호
ordin   자치법규    MST=자치법규일련번호   ← 이쪽만 MST 다
```

**법제처가 이 실패를 「공동활용 미신청」이라고 안내한다.** 권한 문제가 아니라
**파라미터 문제**인데 안내가 딴 데를 가리킨다. 2026-08-28 에 이것 때문에 152가지를
통째로 못 받고 **「계정 권한이 없다」고 몇 시간 헛짚었다.**

⇒ **안내 글자를 믿지 말고 다른 열쇠를 넣어 볼 것.**  [[조용한실패]]

`MST` 밖에 없으면 `&efYd=시행일자` 를 붙이는 길도 열린다(같은 글자를 준다 — 건축법
256,414자로 동일 확인).

## ⚠⚠ 열쇠가 **또 다르다** — 판본은 세 번째 조합이다

    판본 목록   lawSearch.do?target=eflaw&query=<법령명>       ← 시행일자 + 판본별 MST
    판본 본문   lawService.do?target=eflaw&MST=<판본MST>&efYd=<시행일자>   ✔
                lawService.do?target=law  &MST=<판본MST>                  ✔ (조금 짧다)
    ✖ ID=<법령ID>&efYd=…    **HTTP 500**
    ✖ MST=<판본MST> 만       「공동활용 미신청」 오류 화면 1,455자

**현행을 받을 때(`ID=법령ID`)와 열쇠가 다르다.** 안내 글자를 믿지 말고 조합을 바꿔 볼 것.

> *"건축조례는 전국 기초를 다 받지 … 건축조례, 도시계획조례 이거는 많이 사용하는거같으니까"*
> (그전 2026-08-29 방침은 *"지역별로 필요한 경우"* 였다. **바뀌었다.**)

```bash
python 10_Ai/1_법DB/0_원본/받기/법령받기.py --조례받기 --전국 --핵심만   # ★ **243곳 · 건축ㆍ도시계획만**
python 10_Ai/1_법DB/0_원본/받기/법령받기.py --조례받기 --구 강남구,송파구
python 10_Ai/1_법DB/0_원본/받기/법령받기.py --조례받기 --지자체 "부산광역시 해운대구"
python 10_Ai/1_법DB/0_원본/받기/법령받기.py --조례목록 --지자체 "경기도 성남시"   # 받지 않고 무엇을 고를지만
```

    **977개**  (2026-09-07 · 전엔 618)  ·  「건축조례」로 물으면 조문 **1,835건**

⚠ **`--핵심만` 이 없으면 갈래 15가지로 골라 한 곳에 40건**이 걸린다 — 전국이면 **1만 건**이다.
  `--핵심만` 은 이름 **끝**으로 고른다: `… 건축 조례` · `… 도시계획 조례`(+시행규칙).
  「건축기본 조례」ㆍ「녹색건축물 조성 지원 조례」ㆍ「도시계획 토지구획정리사업 시행 조례」는 **안 걸린다.**

⚠ **`--전국` 은 목록을 손으로 안 적는다** — `전국지자체()` 가
  `02_프로젝트/system_설정/data/address_db.json` 에서 **광역 17 + 기초 226 = 243곳**을 짓는다.
  일반구(`수원시 장안구`)ㆍ세종 하위 동ㆍ제주 행정시는 **자치단체가 아니라** 거른다.
  거르지 않으면 317곳이 되고, 거르면 알려진 값 **243** 과 딱 맞는다.

⚠⚠ **그런데 법으로 짐작하면 틀린다** — 같은 자치구인데 **도시계획 조례는 있다**

⚠ 이 표가 없으면 다음 사람이 「도시계획 94/157」을 보고 **「우리가 절반을 안 받았다」**고 읽는다.

**이름을 짐작하지 않는다** — 법제처가 준 그 지자체의 자치법규 목록에서 **갈래 15가지**에
걸리는 것만 고른다(주차장ㆍ건축ㆍ도시계획ㆍ도로점용ㆍ수수료ㆍ녹색건축 …).

⚠⚠ **군은 「군계획 조례」라 부른다** (2026-09-08 에 고쳤다). `(건축|도시계획) 조례` 만
  받던 탓에 시군 **57곳**이 「없다(⑴)」로 찍혔는데 **이름이 달랐을 뿐**이다 —
  `_위임.json` 이 「군계획 조례」를 **637번** 댄다. 이제 꼴 넷을 받는다 —
  도시계획ㆍ**군계획**ㆍ도시 계획(빈칸)ㆍ관리계획.
  ⇒ 꼴은 **`법령받기.조례갈래꼴` 한 곳**에 있고 `조례대장.py` 가 그것을 가져다 쓴다.
  ⚠ **아직 받지는 않았다** — 받을지는 사람이 정한다(`법DB_보완할점_260907.md` §4-1).
갈래는 새로 지어낸 것이 아니라 **창고에 이미 있던 18개의 갈래**를 그대로 넓힌 것이다.

    서울 25개 자치구   전체 ~500건/구 중 **20~30건**씩 → 조례 18 → 575 (2026-08-29 실측)
                     **2026-09-07 현재 조례 977** — 건축ㆍ도시계획을 전국 243곳에서 받았다
⚠⚠ **기관 이름이 두 꼴로 온다.** 법제처 목록은 「**충청남도** 금산군」이라 적는데
  「충청남도 금산군」으로 **찾으면 0건**이다. 「금산군」으로 찾아야 544건이 온다.
  2026-09-05 까지 고르는 쪽이 딱 맞추기만 해서 **544건을 받아 놓고 하나도 못 골랐다.**

## 어느 조문을 다룬 해석인가 — **DRF XML 에는 없다**

`관련조문` 필드가 아예 없다. 그것은 **LSW 화면**에 있다 —

```
https://www.law.go.kr/LSW/expcInfoR.do?expcSeq=<ID>          약 5~8KB
javascript:fncLawPop('건축법','JO','006902000',…)             건축법 **제69조의2**
javascript:fncLawPop('건축법시행령','BE','000100',…)           시행령 [별표 1]
```

**자리 코드는 `조 4 + 가지 2 + 항 3`** (2026-08-28 실측) —

    006900000 → 제69조        006902000 → 제69조의2
    007300000 → 제73조        000600001 → 제6조제1항

법령 때와 **똑같은 두 갈래**(XML 본문 + HTML 링크자리)다. 짐작할 것이 없다.

⚠⚠ **한 링크가 여러 조를 담는다** — `^` 로 이어 붙여 온다.

    '000300000^000900001'                       제3조 · 제9조제1항
    '001300000^001400000^001500000^001600000'   제13조~제16조
    도시개발법 하나에 **51개**가 들어온 것도 있다

  이것을 몰라 2026-08-28 에 **616개 링크를 통째로 버리고 있었다.** `코드쪼개기()` 로
  쪼갠 뒤 `자리풀기()` 를 태운다. 고치니 **조를 읽은 것이 101,877 → 104,235** 가 됐다.

⚠ 목록 안에 **8자리**가 섞여 온다(`00380000`). 9자리 규칙과 안 맞는다.
  **짐작해서 0을 붙이지 않는다** — 201개를 그대로 두고 「안 읽는다」로 센다.

⚠ `fncLawPop` 은 법령ID가 아니라 **이름**(띄어쓰기 없음)을 준다 → `색인.다듬기()` +
  `10_Ai/3_한국건축규정/system_지난것/옛규칙/자료/법령별칭.yaml` 이 받는다. 안 맞으면 **짐작하지 말고 탈에 적는다.**

⚠ 자릿수가 9가 아니면 `자리풀기()` 가 **`(None,None,None)`** 을 돌려준다 — 0 으로 채우지
  않는다. 「못 읽은 코드」가 몇 개인지가 잣대다.

붙이는 것은 `10_Ai/1_법DB/짓기/붙이기.py --해석례링크` 다.
