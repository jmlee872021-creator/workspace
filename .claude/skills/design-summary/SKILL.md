# 설계개요 → Revit

> 상위 : `revit-map`
> 앞 : 건축물대장ㆍ모델 값 (`site-info` 산출물)
> 다음 : `revit-modeling`
> 넘기는 것 : 설계개요 표 (원장ㆍ삽입용)

**한 줄** 값은 **원장 한 곳**에 모으고, 표·계산·판정은 **기계**가 하고,
Revit 에는 **좌표까지 다 정한 배치계획**을 넘긴다.

> 사용자 (2026-09-01): *"데이터 양식은 나랑 대화를 통해 정리하고 / UI는 기존 설계개요를 참고하면 될꺼같아 / 뭔가 파이프라인을 만들고 싶어"*
> *"파이프라인 구축으로 보면은 **네가 드래프팅뷰를 만들고 넣어도 되었겠다**"*

## 0. 시작하기 전에 — 신축인가 증축인가

**이걸 먼저 가른다. 표의 열 구성이 통째로 달라진다.**

```
증축·설계변경   변경전 / 기허가 / 제N회 설계변경 / 비고     ← 예시도면 A-002 (마천동)
신축            항목 / 계획 / 법정 / 판정                  ← 2026-09-01 사용자 확정
표시변경·용도변경  항목 / 변경 전 / 변경 후 / 비고           ← 2026-10-05 사용자 (안국동 52-5 · 캐드 작업공간 A-001)
```

**표시변경ㆍ용도변경 꼴** (2026-10-05 사용자 — 본보기 `02_프로젝트/(261001) 종로구 안국동 52-5/안국동 52-5 표시변경.dxf` 「작업공간」)
- 건축개요 — 변경 전은 건축물대장 값 · ★주용도는 큰 분류(「근린생활시설」) · ★변경 후 칸은 모두 「-」 + 비고 「변경없음」 (*"변경후는 다 '-'로 넣어서 비고란에 '변경없음'"*)
- 층별개요 — 「구분 · 바닥면적 · 변경 전 용도 · 변경 후 용도 · 비고」 · ★대장에 실이 둘로 나뉜 층은 줄도 둘 (*"실을 2개로 표현해야"*)
- 정화조ㆍ주차 — 변경 전 · 변경 후 · 기존 시설(추가 확보) 다음에 ★「검토 결과」 줄 — 적법성 문구 (*"'기존시설 (…25인용) > 변경 후 합계(24.23인) 으로 적법' … 주차부분도 마찬가지"*)
  기존 시설을 넘으면 하수도법 시행령 제25조② — 하수처리구역 밖 120% 이하(6개월마다 청소) · 안 200% 이하(150% 이하 9개월 · 초과 6개월)
  ★서울 주차 — 대지가 설치제한지역(조례 제21조 · [별표 3] 비고 1의 지역 가운데 상업ㆍ준주거 · 걸친 대지는 제한지역이 과반)이면 [별표 2] 가 아니라 [별표 3] 이고, 그 값은 ★최고한도다(근생ㆍ숙박 268㎡당 1대 · 시행규칙 제7조의2③)
  ★용도변경되는 부분이 1대 미만이면 0 대로 적는다([별표 2]ㆍ[별표 3] 비고 — 나눠 한 용도변경의 합이 1대 이상이면 아님) · 「첫째자리까지」 는 여러 용도를 합산할 때의 규칙이다
    (2026-10-10 서초동 1361-10 — 「233.48 ÷ 268 = 0.8 대」 로 넣었다가 사용자 *"시설면적 233.48 / 268 이 이상한데? · 숙박시설이 268m2당 1대야?"* → 「= 0.87 · 1대 미만이라 0 대 · 최고한도」 로 고침)
- 지구단위계획구역이면 ★「바꾸는 용도가 허용ㆍ불허 용도에 걸리지 않는다」 표 — 구분 · 변경 후 용도 · 바닥면적 · 불허용도 · 해당 여부 + 가맹ㆍ체인 · 허용용도 · 근거(고시) 줄
  ⚠ 허용 방식 구역과 불허 방식 구역이 갈리면 ★그 대지가 어느 구역인지가 결론을 가른다 — 결정도ㆍ필지 화면으로 먼저 잡는다 (북촌 : 1ㆍ2ㆍ3ㆍ5 허용 · 4ㆍ6 불허)
- 그린 코드 = `초안/60_표시변경_설계개요.py`(처음 판) · `61_표시변경_고침.py`(위 고침) — 초안 40 의 표 엔진 그대로 · 일 json 은 스크래치 경로라 읽고 고쳐 쓴다

예시도면과 예시엑셀은 여기 있다. **UI 는 여기를 본다.**
`14 revit jakin 템플릿/07 도면/011 설계개요/`
 · `A002 설계개요 260717.pdf` — 배치(좌: 건축개요·층별개요 / 우: 정화조·주차·일괄처리사항)

## ⚠⚠ 신축이면 건축물대장으로 설계개요가 안 채워진다

```
대장이 준다     대지위치 · 도로명주소 · 지역지구 · (참고)대지면적 · 기존건물 현황
대장이 못 준다  주용도 · 건축면적 · 연면적 · 용적률산정면적 · 건폐율 · 용적률
                규모 · 구조 · 지붕 · 최고높이 · 조경면적
                층별개요 · 세대 · 정화조 계획 · 주차 계획
                ───  표의 몸통 전부.  이건 「설계값」이라 사람이나 모델에서 온다
```

신축 대상지의 대장은 **멸실될 기존 건물**이다. 그 값을 씨앗으로 넣어도 되지만
**반드시 「⬜ 기존건물(대장) 값 — 신축 계획으로 바꿀 것」 이라고 붉게 적어 둔다.**
씨앗이 조용히 살아남으면 남의 건물 값이 설계개요에 실린다 (실제로 그럴 뻔했다 — 함정 4).

## 2. ★ 06번이 먹는 규격 — 이걸 어기면 표가 안 나온다

```
1행     B열부터가 열너비(mm).  A1 은 잘려나가므로 아무거나 좋다
```

## 3. 계산 규칙 — 여기서 제일 많이 틀린다

### ★★ 「연면적제외」는 바닥면적에서 이미 빠진 것이다

```
❌  연면적 = Σ 바닥면적,  용적률산정 = Σ (바닥면적 − 연면적제외)     ← 두 번 뺀다
✔  바닥면적이 애초에 제외분을 뺀 값.  용적률산정에서 빠지는 것은 지하층뿐
```

**장애인용 승강기**는 건축법 시행령 §119① **2호(건축면적)와 3호(바닥면적) 양쪽**에서 빠진다.
그래서 건축면적에도 안 들어간다. 예시도면(마천동)의
「장애인ELEV 신설에 의한 **건폐율 감소** (−3.02%)」가 그 뒷받침이다.

표기는 예시도면대로 — **그 층 밑에 딸린 줄**로 적고 소계에는 안 넣는다.

```
1층      18.13㎡  도시형생활주택(원룸형)   18.13㎡   필로티 — 주차부는 바닥면적 제외
          4.59㎡  장애인ELEV (연면적제외)      -
2층      97.87㎡  도시형생활주택(원룸형)   97.87㎡   기준층
          4.59㎡  장애인ELEV (연면적제외)      -
```

### 층수와 용도 — 공동주택은 층수로 이름이 바뀐다

```
주택으로 쓰는 층수 5개층 이상            →  아파트
              4개층 이하 · 660㎡ 초과   →  연립주택
              4개층 이하 · 660㎡ 이하   →  다세대주택
1층을 필로티 주차로 쓰면 그 층은 주택 층수에서 뺀다
```

도시형생활주택은 **주택법상의 유형**이고 건축법 용도는 위 셋 중 하나다.
단지형 연립·단지형 다세대는 **건축위원회 심의를 받으면 5개층까지** 가능하다
(주택법 시행령 §10① 단서). ⬜조문 원문 미확인.

### 주차 — 세 방식이 있다

```
면적당    대수 = 시설면적 / 원단위        근생 134㎡/대 (서울시 조례 [별표2] 3호)
주택식    50㎡ 이하 0 · 150㎡ 이하 1 · 초과분 100㎡당 1대 추가   (단독·다가구)
세대당    세대별 전용면적 구간요율        소형주택 전용 30㎡ 미만 0.5 / 이상 0.6
제외      시설면적을 아예 쓰지 않는다     계단실 등 공용부 — 세대당으로 이미 셌으므로
```

⚠ **세대당으로 세는 주택의 공용부(계단실 등)를 면적으로 또 세면 이중 계상이다.**
02_원단위에 `계단실 | 제외` 로 넣어 표에 「제외」라고 찍히게 한다 — 안 보이게 지우지 않는다.
정화조도 같다. 계단실은 오수가 없으니 `N = 0` 으로 넣어 「0.00인」이 보이게 한다.

⚠ **시설물 종류별로 센다.** 「다가구주택(2가구)」와 「(1가구)」를 딴 용도로 묶으면 대수가 달라진다
(주차장법 시행령 [별표1]). 53번은 원단위표 이름으로 다시 묶는다.
⚠ 시설면적은 **공용면적 포함** 바닥면적 합계, **주차를 위한 시설의 바닥면적은 뺀다** (비고2).
⚠ 소수 이하 **0.5 이상이면 1로 본다** (비고6).

### 정화조 · 조경

```
정화조   인원 = Σ (용도별 면적 × 오수 원단위 N)
         ⚠ 하수처리구역이면 오수관로 직결이라 정화조가 아예 면제될 수 있다 — 먼저 확인
조경     대지면적 200㎡ 미만이면 대상이 아니다 (건축법 §42①)
```

### ⬜ 표시 규칙

법정 원단위·조례 수치는 **조문 원문을 못 폈으면 반드시 `⬜`** 를 붙이고 근거 칸에 어디를 볼지 적는다.
법제처 MCP 는 인증이 필요해 세션에 따라 못 쓴다 — 그때는 `⬜` 인 채로 넘긴다.
확인된 것만 `⬜` 를 지운다. **예시도면에서 뒷받침되는 값은 「예시도면(마천동)에서 확인」이라 적는다.**

```
1  주용도            ← 이게 정해져야 층별 용도·주차 원단위·정화조 원단위가 다 따라온다

4  건축면적           비어 있으면 건폐율 칸이 안 나온다
5  지하층             있나 없나 · 용도
6  주차 기준          면적당인가 세대당인가 · 구간요율
7  계획 주차대수       「법정에 맞출 것」이면 미정으로 둔다
8  정화조             하수처리구역인가 · 형식·용량
```

**답이 「미정」이면 0 이 아니라 미정으로 둔다.** 0 으로 두면 「부적합」이 찍혀 거짓이 된다.

넘는다는 사실을 한 번 말하고, 어떻게 할지는 사용자가 정한다.

## 5. Revit 에 넣기

### 뷰

드래프팅 뷰. **없으면 만든다** — 사람에게 시키지 않는다.
축척은 **시트 크기에서 거꾸로 정한다** (아래 「축척」 절). A3 시트면 **1:2**.

```python
from Autodesk.Revit.DB import ViewDrafting, ViewFamilyType, ViewFamily
vft = [x for x in FilteredElementCollector(doc).OfClass(ViewFamilyType)
       if x.ViewFamily == ViewFamily.Drafting][0]
view = ViewDrafting.Create(doc, vft.Id)
view.Name = u"설계개요"
view.Scale = 2          # A3 시트 기준. 아래 「축척」 절을 먼저 볼 것
```

### ★★ 축척 — 여기서 제일 헷갈린다

```
DetailLine   모델 크기다.  1:2 면 종이에서 절반이 된다
TextNote     종이 크기다.  1:2 여도 안 줄어든다 → 칸에 비해 글씨가 두 배로 커 보인다
```

그래서 **줄 접기는 「모델폭 ÷ 축척」을 종이폭으로 삼아야** 한다. 안 그러면 글이 칸을 넘친다.
글 넣는 자리의 여백도 종이 기준이라 **모델 좌표로는 축척배로 벌려야** 한다.
53번은 `build --scale 2` · `place --scale 2` 로 이걸 받는다.

**시트에 맞추기** — A3(420×297)에 표제란을 빼면 그림영역은 약 **345 × 281mm**.

```
1:1  표 736mm  →  종이 736mm   ❌ A3 는커녕 A1 도 빠듯
1:2  표 658mm  →  종이 329mm   ✔  글씨는 2.1mm 로 낮춘다
```

축척을 바꾸면 **글씨 크기도 같이 내려야** 한다. 1:1 이면 `JL_2.4mm_돋움`, 1:2 면 `JL_2.1mm_돋움`.

**행 높이는 종이에서 5mm 는 되어야 한다.** 1:2 면 모델 10mm (`Table.LINE_MM`).
4mm 로 잡았더니 「행 높이가 너무 낮다」는 말을 들었다.

**글자폭 어림은 넉넉히 잡는다** (`KO_MM`). 짧게 잡으면 줄이 안 접혀 **옆 칸을 침범한다** —
모자란 쪽이 넘치는 쪽보다 낫다.

### 그리기

`place` 가 뽑은 `05_설계개요_배치계획.json` 을 읽어 그린다. **mm · y 는 아래로 증가** →
Revit 에서는 `X = x/304.8`, `Y = −y/304.8`.

```python
p1 = XYZ(L[0]*MM, -L[1]*MM, 0.0); p2 = XYZ(L[2]*MM, -L[3]*MM, 0.0)
doc.Create.NewDetailCurve(view, Line.CreateBound(p1, p2))
TextNote.Create(doc, view.Id, XYZ(tx["x"]*MM, -tx["y"]*MM, 0.0), tx["s"], opts)
```

문자 유형은 사무실 것을 쓴다 — 제목 `JL_3.3mm_돋움`,
칸은 축척에 맞춰 **1:1 이면 `JL_2.4mm_돋움` · 1:2 면 `JL_2.1mm_돋움`**.

### ★ 다시 그릴 때는 ID 목록으로 지운다

```
❌ 좌표 범위로 지우기 — 사용자가 그려 둔 것까지 지운다
✔ 지난 회차에 내가 만든 ID 만 지운다.  06_그린요소_ID.json 에 남겨 둔다
   지울 때 e.OwnerViewId == view.Id 도 확인한다
```

### ★ 뷰포트 자리잡기는 두 번 해야 한다

`GetBoxOutline` 은 **같은 트랜잭션 안에서는 갱신 전 크기**를 준다. 표를 그린 직후에 읽으면 어긋난다.
그리기를 **커밋한 뒤** 새 트랜잭션에서 읽어 옮기고, 한 번 더 읽어 확인한다.

```python
for _pass in range(2):
    t = Transaction(doc, u"뷰포트 자리잡기"); t.Start()
    ob = vp.GetBoxOutline()
    dx, dy = 12.0 - ob.MinimumPoint.X*304.8, 284.0 - ob.MaximumPoint.Y*304.8
    c = vp.GetBoxCenter(); vp.SetBoxCenter(XYZ(c.X + dx*MM, c.Y + dy*MM, 0.0))
    t.Commit()
```

### 캡처

`revit_view_png` 는 **같은 이름의 시트가 있으면 그쪽을 잡는다** (실제로 그랬다).
드래프팅 뷰는 `Duplicate` 가 안 돼 `crop_mm` 도 못 쓴다. `ExportImage` 로 뷰 Id 를 콕 집어 내보낸다.


## 6. 함정 — 전부 실제로 값을 틀리게 했다 (2026-09-01)

| | 무엇 | 왜 |
|---|---|---|
| 1 | `is_underground` 가 늘 참 | `u"%s" % (name or u"").strip().startswith(...)` — `%` 가 메서드보다 늦게 묶여 **bool 을 문자열로** 만든다. `"False"` 도 참이다. 전 층이 지하로 분류돼 지상 연면적이 0 이 됐다 |
| 2 | 병합하면 값이 사라진다 | 엑셀 병합은 **왼쪽 위 칸만** 남긴다. 값을 오른쪽에 넣고 병합해 정화조 「합계 …인」과 주차 산출식이 날아갔다. **병합 전에 값을 왼쪽 위로 끌어올린다** |
| 3 | 주차를 가구 수로 쪼개 셌다 | 시행령 [별표1] 은 **시설물 종류**별로 세라고 한다 |
| 4 | 씨앗(대장) 용도가 조용히 살아남았다 | `pull` 이 면적만 모델로 갈고 비고를 「모델에서 뽑음」으로 덮어 **용도 경고가 사라졌다.** 안 갈린 칸의 경고는 지우지 않는다 |
| 5 | 글이 칸을 넘쳤다 | Revit `TextNote` 는 **스스로 줄을 안 접는다.** 열 너비(병합이면 걸친 폭)에 맞춰 `\n` 을 넣고 행높이를 늘린다 |
| 6 | 연면적제외를 두 번 뺐다 | §3 참조. 연면적이 23㎡ 부풀었다 |
| 7 | `ws.cell(r, c, None)` 이 안 지운다 | openpyxl 은 `value=None` 을 「값을 안 준 것」으로 보고 **무시한다.** `ws.cell(r,c).value = None` 이라야 한다. 계획대수 0 이 남아 「부적합」이 찍혔다 |
| 12 | `pull` 이 사람 값을 지웠다 | 모델에 면적요소가 없는 층을 0 으로 만들어 **사람이 넣은 계획이 날아갔다.** 모델에 없으면 원장 값을 살리고, 모델에도 원장에도 없는 레벨(Roof 등)은 아예 행을 안 만든다 |
| 11 | `pull` 이 바닥면적에 제외분을 더했다 | 면적요소를 다 더해 놓고 「연면적제외」를 따로 적었더니, 뒤에서 또 빼는 구조가 됐다. **바닥면적은 제외분을 뺀 값**으로 넣는다 |
| 10 | 그림영역을 뷰포트 선으로 착각했다 | 표제란 칸막이를 찾을 때 높이 조건이 느슨해서 **이미 올려둔 뷰포트의 테두리**를 골랐다. 테두리 높이를 95% 이상 채우는 선만 센다. 가장 확실한 건 **빈 시트에서 재는 것** |
| 9 | 1:2 로 줄이니 글이 칸을 넘쳤다 | **TextNote 는 종이 크기라 축척만큼 안 줄어든다.** 칸만 반이 되고 글씨는 그대로여서 넘쳤다. 줄 접기가 축척을 알아야 한다 |
| 8 | 구간표의 마지막 줄이 사라졌다 | 세대당 요율표의 「상한 없음(그 이상 전부)」 줄은 A열이 비어 있다. A열이 비면 건너뛰게 해 놨더니 그 줄이 통째로 없어졌다 |

**그 밖**
- `⬜` 는 Revit 한글 폰트에 글리프가 없어 두부(□)로 나온다 → **삽입용에서만 `※`** 로 바꾼다. 원장(엑셀)은 `⬜` 그대로.
- MCP `revit_exec` 는 `exec(code, globals, locals)` 로 돌아서 **함수 안에서 바깥 이름이 안 보인다.** 함수를 정의하기 전에 `globals()["x"] = x` 로 올려 둘 것.

---

## 7. 안 하는 것

- **숫자를 예쁘게 만들지 않는다.** 법정을 넘으면 「부적합」이라고 찍고 그대로 둔다.
- **모델을 고치지 않는다.** 레벨이 모자라거나 면적요소가 없으면 표에 `⬜` 로 남기고 알린다.
- **사용자가 배치한 것을 지우지 않는다.** 다시 그릴 때는 내가 만든 ID 만.
- **조문을 지어내지 않는다.** 못 폈으면 `⬜`.
- **완화를 받는 값은 표기와 판정을 따로 둔다.** 원장에 `법정용적률 표기` 를 두면 표의 법정 칸에 그 글이
  그대로 가고, `법정용적률` 숫자는 판정에만 쓴다 — 「200% (…에 따라 한시적 250%)」 라고 적으면서
  판정은 250 으로 하는 식이다. 표기만 바꾸고 판정을 안 바꾸면 표가 스스로 어긋난다.
- **층수는 세어 낸 것과 적는 것이 다를 수 있다.** 원장 `층수` 에 적으면 그 글이 그대로 간다
  (「지상4층 (필로티 1개층, 포함 5개층)」 따위).

## 9. 2026-09-02 에 바뀐 것 (쌍문동 315-232)

### 9-1. ★ 제외가 두 갈래다 — 섞으면 값이 틀린다

| 모델 주석 | 바닥면적 | 용적률 | 건축면적 | 보기 |
|---|---|---|---|---|
| `면적제외` | **이미 빠져 있다** | 빠짐 | 빠짐 | 장애인용 승강기 |
| `면적제외` | **이미 빠져 있다** | 빠짐 | **들어감** | 발코니(깊이 1.5m 이내) |
| `용적률제외` | **들어 있다** | 빠짐 | 들어감 | 지하층 · 지상 주차용 부분 · 피난안전구역 |

원장 `■ 층별` 이 **6열 → 8열**이 됐다.
```
층 · 바닥면적 · 용도 · 연면적제외 · 제외사유 · 용적률제외 · 용적률제외사유 · 비고
```
옛 원장(6열)도 그대로 읽고, `pull` 한 번에 머리글이 올라간다.

**발코니는 「용적률만 제외」가 아니다.** 건축법 시행령 §119①3호나목 —
노대 면적에서 「접한 가장 긴 외벽 길이 × 1.5m」를 뺀 만큼만 바닥면적에 산입한다.
깊이 1.5m 이내면 **바닥면적에서 통째로 빠지고**, 따라서 연면적에도 안 들어간다.
용적률에서만 빠지는 것은 영 §119①4호 각 목에 열거돼 있고 **발코니는 거기 없다.**
다만 **건축면적에는 남는다**(외벽 안쪽이면 그대로, 1m 이상 돌출이면 1m 후퇴).

### 9-2. 같은 단에 쌓이는 표는 전체 폭을 맞춘다 — 기본이다

모자란 만큼은 **그 표에서 가장 넓은 칸**에 준다 — 오른쪽 끝 숫자 칸이 제자리로 밀려 나란히 선다.
좁은 숫자 칸을 넓히면 숫자가 왼쪽에 붙은 채 칸만 커져 보기 나쁘다.
