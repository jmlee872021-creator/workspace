# 공통 도구 지도 — 어느 일감에서나 쓰는 것

> 📄 사용자 (2026-09-17) : *"스킬들이 중구난방으로 분류되어있는거 같은데 스킬들을 잘 분류해야되는거 같아"* → Q1 ① 일감 다섯 묶음마다 지도 하나

**이 스킬은 얇게 둔다.** 차례가 있는 일감이 아니라 필요할 때 부르는 도구다.

## 1 · 언제 무엇을

```
로그인이 필요한 웹을 보거나 받아야 한다        web-access
pptx 쪽번호ㆍ머리말 같은 되풀이 양식을 고친다    pptx-form
원본을 다른 꼴로 옮기고 맞는지 증명해야 한다      source-fidelity
아이폰에서 옮긴 사진이 안 열린다 (애플펜슬 표시)  photo-normalize   ← 묻지 않고 바로
구청ㆍ소방서 조직도를 받아 담당 전화를 모은다      agency-orgchart   (업무매뉴얼 사무소 자료 › 관계부서)
매뉴얼 「AI 작업 흐름」 메뉴에 기능을 더하고 고친다   ai-workflow-manual  (기능의 스킬 → 기능장뽑기.py → 장)
사용자가 읽는 글의 말투를 맞추고 잰다               writing-style      (채팅 답변ㆍ매뉴얼ㆍ보고서ㆍ도면 메모 · 초안 2026-10-03)
「표시했어」 — 검토 화면의 그림에 넣은 표시를 읽는다   스킬 없음 → 아래 2절  (도구 `검토답서버.py --표시`)
```

## 2 · 그림 표시 — 「표시했어」 (2026-10-09 사용자 Q4 ①)

> 📄 사용자 : *"이미지를 클릭했을때 이미지에 간단한 표기 (선이나 네모, 등)을 해서 뭔가 완료를 누르면 너에게 전송되게"* · *"너와 나의 의사소통을 가볍게 진행하는 방법"*

사용자는 검토 화면(html)의 그림을 눌러 크게 띄우고, 선ㆍ화살표ㆍ네모ㆍ표시점ㆍ글을 넣은 뒤 「완료」 를 누른다. 그리고 채팅에 「표시했어」 라고 한다.

선과 화살표는 점을 차례로 눌러 긋는 꺾인 선이다(2026-10-09 사용자 *"polyline 기능이 없어"* · *"선은 화살표 선을 표현하는게 있으면 좋을 것 같은데"*). 두 번 누르기, Enter, 오른쪽 단추 가운데 하나로 끝낸다. 한 번 끌면 곧은 선 하나가 된다. 읽은 글에는 점이 누른 차례대로 나온다. 화살표는 「화살촉이 가리키는 곳」 이 따로 나온다. 화살표의 끝점이 사용자가 가리킨 대상이고, 첫 점은 말을 꺼낸 자리다.

이 기능을 고치거나 이어서 만들 때는 `00_길잡이/이어서/그림표시.md` 부터 읽는다.

그 말을 들으면 먼저 읽는다. 대지를 모르면 지금 일하던 대지로 읽고, 그것도 없으면 어느 대지인지 여쭌다.

```
python 02_프로젝트/system_만들기/검토답서버.py --표시 "<대지 이름 일부>"
```

읽은 글에는 그림마다 번호ㆍ종류ㆍ자리ㆍ글이 있고, 지난번 읽은 뒤 새로 넣은 것에 ★ 가 붙는다. 「표시가 얹힌 그림」 의 길이 함께 나오니 그 그림을 Read 로 열어 어디를 가리키는지 눈으로 본다. 표시가 한쪽에 몰려 있으면 「표시 둘레만 자른 그림」 도 나온다. 자리는 그림 너비ㆍ높이에 대한 비율(왼쪽 위가 0,0)이다.

답할 때는 표시 번호를 그대로 부른다(「① 선은 건축선을 가리키신 것으로 읽었습니다」). 번호가 무엇을 가리키는지 그림으로도 못 가르면 그 번호만 되묻는다.

- 「그림 표시가 없다」 로 나오면 답 저장이 꺼져 있던 것이다. 「답 저장을 켤까요」 를 뿌리 CLAUDE.md §2 꼴로 여쭙고 켠다(따로 최소화 창). 켜지면 화면이 브라우저에 남겨 둔 표시를 스스로 보낸다.
- 화면의 그림을 눌러도 안 뜨면 그 화면에 아직 안 붙은 것이다. `--표시붙이기 "<화면 html>"` 로 붙인다. 어느 화면에 붙일지는 사용자가 정했다 — 지금은 마천동 35-5 규모검토뿐(Q2 ①). 다른 화면은 여쭙고 붙인다.
- 화면을 다시 뽑으면 붙인 두 줄이 사라진다. 그 화면을 짓는 도구에 `그림표시.붙인글(html글, html길)` 한 줄을 넣는다. 넣은 표시는 화면을 다시 뽑아도 남는다(파일 이름 뒤의 시각을 떼고 본다).
- 「표시하기」 단추는 그림 오른쪽 위에 늘 보인다. 마우스를 올려야만 뜨던 때에 사용자가 「그림 표시기능이 없는거 같은데?」 라고 했다(2026-10-09).
- 이 앱의 옆 칸에서 화면 파일을 열면 표시가 안 된다. 멈춘 사본이라 그림 27장 가운데 0장이 뜬다. 탐색기에서 열어야 한다.

**「열기」 고리로 연 화면(Artifact)에서 넣은 표시** (2026-10-09 사용자 Q1 ① 「1번 해보자」 · ⏸ 사용자가 그 화면에서 실제로 눌러 본 것은 아직 없다)

그 화면은 이 컴퓨터의 답 저장에 닿지 못한다. 그래서 표시를 그 화면에 딸린 저장소에 두고, 「표시했어」 를 들으면 받아 와서 대지 폴더의 같은 기록에 옮긴 뒤 읽는다. 세 걸음이다.

```
① ArtifactData  action "list" · url <그 화면의 고리> · collection "marks" · out_dir <받아 둘 폴더>
     ⚠ out_dir 는 C:\Users\Administrator\… 꼴의 긴 길로 댄다 — ADMINI~1 꼴은 막힌다
② python 02_프로젝트/system_만들기/검토답서버.py --표시받기 "<대지 폴더의 화면 html>" --받은것 "<받아 둔 폴더>"
③ python 02_프로젝트/system_만들기/검토답서버.py --표시 "<대지 이름 일부>"
```

- ①에서 「No documents matched」 면 그 화면에서 넣은 표시가 없는 것이다. 컴퓨터에서 연 화면에 넣었을 수 있으니 ③은 그대로 돌린다.
- ②는 그림 한 장을 통째로 바꿔 쓴다. 대지 폴더 쪽 표시가 더 나중 것이면 두고 알린다. 지난번에 옮긴 그대로면 다시 적지 않는다.
- 그 화면을 지을 때 넣는 것은 셋이다. 그림마다 `data-그림="<화면 폴더에서 본 그림 길>"`, 화면 끝에 `window.그림표시설정={"저장":{"꼴":"artifact"},"화면":"<화면 열쇠>"}` 와 `그림표시.js` 글 전체, 올릴 때 `capabilities: {"db": {}, "user": {}}`. 본보기는 마천동 규모검토를 짓는 `page.py`(자리는 `00_길잡이/이어서/대지.md` 맨 위 블록).
- 확인한 것은 둘이다. 저장소를 흉내 낸 시험에서 그리기, 「완료」, 다시 열어 불러오기가 됐다. 제가 저장소에 시험 표시를 넣고 ①②③으로 읽었다. 로그인한 사용자의 화면에서 저장되는지는 사용자가 눌러 봐야 안다(제 브라우저는 로그인이 안 되어 있다).
- 자리ㆍ함정ㆍ잣대는 `00_길잡이/길찾기.md` 「답 저장」 절.
