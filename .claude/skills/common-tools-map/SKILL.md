# 공통 도구 지도 — 어느 일감에서나 쓰는 것

> 📄 사용자 (2026-09-17) : *"스킬들이 중구난방으로 분류되어있는거 같은데 스킬들을 잘 분류해야되는거 같아"* → Q1 ① 일감 다섯 묶음마다 지도 하나

**이 스킬은 얇게 둔다.** 차례가 있는 일감이 아니라 필요할 때 부르는 도구다.

## 1 · 언제 무엇을

```
로그인이 필요한 웹을 보거나 받아야 한다        web-access
pptx 쪽번호ㆍ머리말 같은 되풀이 양식을 고친다    pptx-form
원본을 다른 꼴로 옮기고 맞는지 증명해야 한다      source-fidelity
아이폰에서 옮긴 사진이 안 열린다 (애플펜슬 표시)  photo-normalize   ← 묻지 않고 바로
구청ㆍ소방서 조직도를 받아 담당 전화를 모은다      agency-orgchart   (업무매뉴얼 사무소 자료 › 관계부서)
매뉴얼 「AI 작업 흐름」 메뉴에 기능을 더하고 고친다   ai-workflow-manual  (기능의 스킬 → 기능장뽑기.py → 장)
사용자가 읽는 글의 말투를 맞추고 잰다               writing-style      (채팅 답변ㆍ매뉴얼ㆍ보고서ㆍ도면 메모 · 초안 2026-10-03)
```

## 3 · 하위 스킬 — 받는 것 · 내는 것 · 다음

| 스킬 | 하는 일 | 받는 것 | 내는 것 | 다음 |
|---|---|---|---|---|
| `web-access` | 사람이 열어 둔 브라우저에 붙어 화면ㆍAPI 응답 받기 | 열린 브라우저 | 화면ㆍ응답 기록 | — |
| `pptx-form` | pptx 양식(넘버링ㆍ머리말ㆍ꼬리말) 파악ㆍ고치기 | pptx | 고친 pptx · 벗어난 것 N건 | — |
| `source-fidelity` | 옮긴 것이 맞는지 되돌림ㆍ정답지로 증명 | 원본ㆍ옮긴 것 | 검증 장치 · 어긋남 수 | — |
| `photo-normalize` | 겉 .JPG · 속 아이폰 사진인 것을 속만 보통 사진으로 바꿔 넣기 (2026-09-28) | 사진이 든 폴더 (위 폴더여도 된다) | 바꾼 것 N / N 장 · 다시 잰 것 0 장 | — (사진 내용을 읽으면 `drawing-analysis`) |
| `agency-orgchart` | 관계부서(구청ㆍ소방서) 조직도를 받아 「전화 \| 맡은 일」 장으로 (2026-10-02 · 정본 yaml → `관계부서.py`) | 관계부서 이름ㆍ조직도 주소 | 장 html · 찾기 줄 N / N · 탈 0 | — (사용자가 장을 보고 분야를 짚는다) |
| `ai-workflow-manual` | 업무 매뉴얼 「AI 작업 흐름」 권 — 기능의 스킬에서 장을 뽑고, 메뉴에 기능을 더하고, 「사용자가 정한 것」 표를 고친다 (2026-10-03 사용자 Q7 ①) | 기능의 스킬 · 사용자가 화면에서 짚은 것 | 장 html · `--재기` 낡은 장 0 · 안 가른 스킬 0 | — (사용자가 장을 보고 짚는다) |
| `writing-style` | 사용자가 읽는 글의 말투 - 규칙 열두 가지 · 바꿔 쓴 글 · 재는 도구 · 매뉴얼 「사무소 자료 › 글 쓰는 기준 › 글 문체」 장 (2026-10-03 초안 · 사용자 검토 전 · 정본 yaml → `글문체.py`) | 사용자가 읽을 글 · 사용자가 말투를 짚은 말 | 잰 수 「문장 N · 고칠 문장 N」 · 고친 글 · 정본의 사례 한 줄 | — (그 글을 짓는 스킬로 돌아간다) |
