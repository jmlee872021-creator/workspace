## ⚠⚠ 넘지 않는 선 — 이것부터 읽는다

구조는 **틀리면 사람이 죽는다.** 이 프로젝트에서 「사람확인」 규약이 가장 센 자리다.

    해도 되는 것    · 기준 조항을 **찾아 자리를 댄다** (조항키까지)
                  · 계산서가 쓴 값과 기준값을 **맞대어 같은지/다른지** 낸다
                  · **인용한 판이 현행인지** 잰다
                  · 못 잰 자리를 **세어서 드러낸다**

    하면 안 되는 것  · **「안전하다/위험하다」고 판정하는 것**
                  · 기준값을 **지어내는 것** → 못 찾으면 NULL, 「⏸ 못 찾았다」
                  · 사람확인 칸을 O 로 찍는 것

⇒ 우리가 내는 것은 **「이 값이 이 조항의 이 한계를 넘었다/안 넘었다」** 까지다.

⚠⚠ **「인용 판이 낡았다」와 「그래서 결과가 틀렸다」는 다른 말이다.**
  판이 다르면 **조항을 실제로 열어** 그 값이 바뀌었는지 확인한다. 못 하면 「⏸ 아직 못 쟀다」.
  옛 판을 우리가 안 가졌으면 그것은 **⑵ 우리가 안 가졌다**이지 ⑶ 우리 결함이 아니다.

## ⚠⚠ 두 자 낱말은 색인이 **「0건」**을 낸다

FTS5 trigram 은 글자를 **석 자로 잘라** 색인한다. 구조 낱말에 두 자가 유난히 많다 —
**응력 · 철근 · 강재 · 좌굴 · 지압 · 전단 · 휨 · 기초 · 하중.**

`찾기.py` 가 석 자 미만이면 색인을 안 쓰고 훑으며 「몇 초 걸린다」고 알린다(2026-09-25 부터 색인 표의 글 칸을 훑어 한 번에 2~3초).
**0건이 나오면 「없다」로 단정하지 말고** 석 자 이상으로 다시 물어라
(`전단` → `전단강도`, `기초` → `기초구조`).

    항목        계산서가 쓴 판              **지금 현행**                판정

    지진하중     KDS 41 17 00 **2019**    **2022** (2022-10-13)      ⚠ **3년 낡았다**

    총칙        국토부 고시 **2022-570**   고시 **2024-846**            ⚠ 다르다
                                        (시행 2024-12-24)

⚠⚠ **「고시가 2024-846으로 바뀌었다」를 「KDS 41 전부가 2024판」으로 읽으면 틀린다.**
  우리 창고 33건을 전수로 세니 **2024판은 셋뿐**이다 —
  **411005 총칙 · 412000 콘크리트구조 · 412010 프리캐스트** (셋 다 고친날 2025-01-02).
  나머지 **30건은 2022판이 그대로 현행**이다(2022-10-13/14).
  ⇒ 지진(411700)ㆍ풍(411200)ㆍ기초(411900)ㆍ강구조(413010)는 **2022판이 현행**이고,
    계산서가 지진을 **2019판**으로 계산한 것은 **2022 개정을 안 반영한 것**이다.
    이것이 이번 계산서에서 **가장 무거운 한 줄**이다.

계산 프로그램 출력 머리글에 **판이 박혀 있다** —
`EQUIVALENT SEISMIC LOAD IN ACCORDANCE WITH KOREAN BUILDING CODE (KDS(41-17-00:2019))`.
표지 문구가 아니라 **프로그램이 그 판으로 계산했다**는 더 강한 증거다. 여기부터 본다.

```sql
-- 우리가 가진 판
SELECT 코드, 이름, 판, 고친날 FROM 기준 WHERE 갈래='KDS' AND 코드 LIKE '41%' ORDER BY 코드;
-- 법제처 고시가 현행인가
```

### ★ 본이 이미 있다 — **`jakin-revit` MCP 를 베낀다**

`.mcp.json` 에 등록돼 있고 **서버가 2,741바이트짜리 얇은 것**이다 —

    G:/내 드라이브/Antigravity/14 revit jakin 템플릿/04 revit_자동화코드/revit_mcp_server/server.py

꼴이 셋 — `revit_ping`(떠 있나) · `revit_state`(**묻기 전에 실제 상태를 본다**) · `revit_exec`(코드).
속은 이렇다 —

```python
from mcp.server.mcpserver import MCPServer
server = MCPServer("jakin-revit")
BASE_URL = "http://localhost:48884/jakin-tools"     # pyRevit Routes (Revit 안에서 도는 절반)

@server.tool()
def revit_ping() -> dict:
    return _get("/ping")
```

⚠ **Revit 은 절반이 둘이다** — MCP 서버(밖) + pyRevit Routes(Revit 안).
  **Robot 은 COM(`RobotOM`)이라 밖에서 바로 부를 수 있어 절반 하나면 된다** —

```python
import win32com.client
app = win32com.client.Dispatch('Robot.Application')   # 떠 있는 Robot 에 붙는다
proj = app.Project;  st = proj.Structure
```

⚠ 못 붙었을 때 **무엇을 확인하라고 말할지**까지 베낀다. Revit 것은 이렇게 적어 뒀다 —

  **조용히 죽지 않고 사람이 고칠 수 있게 말한다.**
