> 상위 : `common-tools-map`
> 앞 : 원본과 옮긴 것
> 다음 : — (부른 스킬로 돌아간다)
> 넘기는 것 : 검증 장치 · 어긋남 수

**옛 step01**(한국건축규정 254개 판정)은 맞는지 틀리는지 **견줄 대상이 없어** 검증이

**정답지를 두고** 다시 해서 206행 100% 일치로 끝냈다. 차이는 실력이 아니라 **장치**다.

## ★ 돌려 보는 한 줄 — **장치마다 있다**

```bash
python 03_참조자료/01_법과규제/용인체크리스트/scripts/참고구조.py                    ① 되돌림 (205덩이)
python 03_참조자료/01_법과규제/용인체크리스트/scripts/대조_확장.py                   ③ 채점 (묶음 466 · 어긋남 0)
python 03_참조자료/01_법과규제/용인체크리스트/scripts/닫힘검사.py --확인              ④ 닫힘 + 206행 대조
python 03_참조자료/01_법과규제/용인체크리스트/scripts/판본.py --목록                 ⑤ 판본 v1~v5
```

<sub>그 폴더의 나머지 — `추출.py`(엑셀 → json) · `파트.py`(파트별 가르기) ·
`대조.py`(엑셀 판정 ↔ 우리 판정) · `대조_JS.py`(화면 쪽) · `확장판정.py`(구역 여럿) ·
`붙이기.py` · `판정.py`. **안 적힌 도구는 없는 것과 같다**(CLAUDE.md ⑸).</sub>

  `가이드검사.py` 의 ⑷ㆍ⑺ㆍ`--돌려보기` 는 **`python … .py` 줄이 있어야** 작동한다.

## 다섯 가지 장치

### ① 되돌림 — 푼 것이 맞나
푼 조각을 도로 이어 붙여 **원문과 글자 그대로 같은가.** 같지 않으면 푼 것이 아니라
**바꾼 것**이다. (`03_참조자료/01_법과규제/용인체크리스트/scripts/참고구조.py` — 205덩이 전부 통과)

### ② 줄 검사 — 그린 것이 맞나
화면을 만들 때마다 **줄이 빠지거나 겹치지 않았는지** 센다.
(`03_참조자료/01_법과규제/용인체크리스트/scripts/보고서.py` — 만들 때마다 자동으로 돈다)

### ③ 정답지 채점 — 답이 맞나
사람이 이미 손으로 해 둔 것이 있으면 그것이 채점표다.
용인 참고의 **고리 425개**는 위임 사슬의 **정답지 후보**다 — ⚠ **아직 그것으로 채점하는
코드가 없다**(읽는 파이썬은 `99_기계/06_기록/옛엔진_step01/위임사슬.py` 뿐이다).
지금 본줄기가 실제로 쓰는 정답지는 **`10_Ai/1_법DB/0_원본/위임정보/`**(법제처 위임 431)다 —
`10_Ai/1_법DB/짓기/옮기기.py` 의 53줄이 그렇게 적어 두었다. **이미 있는 채점표를 놔두고
425 쪽에 새로 짓지 않는다.**
없으면 만들어서라도 둔다 — **정답지가 없으면 검증이 불가능하다.**

### ④ 닫힘 — 자료가 늘어 로직이 흔들리지 않게
바깥 자료를 **읽지 못하게 막고** 시작한다. step01 은 토지이음이 들어와 판정이 바뀌고,
조례가 들어와 건폐율 로직이 바뀌고, 별표2가 들어와 목차가 바뀌어 **한 번도 완성된 적이
없다.** (`03_참조자료/01_법과규제/용인체크리스트/scripts/닫힘검사.py`)
열 때는 **무엇을 왜 여는지 적고** 연다.

### ⑤ 판본 — 되돌릴 수 있게
지문(SHA-256)은 「달라졌다」만 알려 주고 **되돌릴 수 없다.** 파일을 통째로 담아 둔다.
(`03_참조자료/01_법과규제/용인체크리스트/scripts/판본.py` — v1~v5)

## 일하는 순서

1. **한 번에 하나씩 바꾼다.** 자료와 로직을 동시에 바꾸면 원인을 못 가린다
2. 바꾼 뒤 **바꾼 것을 한 줄씩 말할 수 있어야 한다.** 못 하면 잘못 바꾼 것이다
3. 고치기 전에 **재 본다.** 추측으로 원인을 말하지 않는다

## 실제로 이 장치들이 잡은 것

| 장치 | 잡은 것 |
|---|---|
| 정답지 | 참고 도형이 **한 칸씩 밀려** 붙음 (제15조 행에 제13조 참고) |
| 정답지 | 판정이 **손으로 적힌 행 2개** — 반영해야 100%가 된다 |
| 줄 검사 | **같은 글자 표지가 한 덩이에 여러 번** — 205덩이 중 25개가 어긋남 |
| 채점 | 항번호가 **동그라미 숫자**, `<항내용>` 이 비어 있음, `제1호의2` 표기 |
| 닫힘검사 | 검사기가 **자기 자신**을 잡음(금지어 목록을 코드에 가짐) |

## ⚠ 어긋난다고 나오면 「재는 자」를 먼저 의심할 것

화면과 파이썬을 지문으로 맞대어 보다 **50가지가 전부 어긋난** 적이 있다.
판정이 아니라 지문이 문제였다 — JS 의 수는 배정도라 FNV-1a 의 `x * 16777619` 가
2^53 을 넘으면 **조용히 깎인다.** 개수는 50가지 모두 같은데 지문만 다른 것이 단서였다.

## ⚠ 재는 자의 눈금이 너무 촘촘하면 아무것도 못 가린다

검수 장치를 만들 때 「받는 조문 제목에 위임 문구의 낱말이 없다」를 **모든 연결에** 붙였더니
**257개 중 201개**가 걸렸다. 전부 의심스러우면 아무것도 의심스럽지 않다.
**근거가 이미 강한 것(조항ㆍ문구까지 맞음)은 빼고, 약한 것에만** 붙이자 26개로 줄었고
그제야 먼저 볼 차례가 생겼다.

같은 이유로 **「자료가 없어서 못 한 것」과 「로직이 틀려서 못 한 것」을 갈라야 한다.**
조례 위임은 지자체 조례가 창고에 없어서 못 잇는 것이지 틀린 것이 아니다 —
둘을 같이 세면 고칠 곳이 안 보인다.

## ⚠ 원문에 없는 것을 지어내지 말 것

별표 칸의 여러 줄을 한 줄로 이어 붙이려다 세 번 실패했다. **한글은 낱말 가운데서도 줄을
끊기 때문에** 「여기가 낱말 사이인가」라는 정보가 원문에 아예 없다.
못 알아내는 것은 **못 알아낸 채로 두고** 원문 그대로 보여 준다.
