# 한글 파일(hwpx) — 한글 없이 읽고, 고치고, PDF 로 뽑고, 남에게 보낼 문서로 정리한다

> 상위 : `doc-form-map`
> 앞 : 확인용 화면(html)이나 사용자가 한글에서 손으로 고친 .hwpx · 「누구에게 보낼 문서인가」
> 다음 : 사용자가 한글에서 열어 보고 저장한다 → 그 파일을 다시 읽어 잇고 PDF 를 뽑는다 · 머리 꼴은 `doc-form`(문서 기본양식)
> 넘기는 것 : 새 이름의 .hwpx(원본은 그대로) · 검사 수(문단ㆍ표ㆍ그림ㆍ탈 0) · 같은 이름의 .pdf · 글과 그림 차례를 보는 미리보기

> 📄 ★목표 — 사용자 (2026-10-08) : *"dxf 제어할때 캐드프로그램 없이 제어하는것처럼, hwp도 한글프로그램 사용하지 않고 제어하고 싶은게 목표야. 왜냐하면 그래야 백그라운드에서 작업하고, 사용자와 충돌하지 않거든"*
> 📄 사용자 (같은 날) : *"네가 작성한거는 '내가' 보기 좋은 방식이야. 그런데 이걸 다른사람에게 전달할때는 좀 정리가 필요해. UI가 너무 복잡해도 어려워"*

**이 스킬은 입구만 둔다.** 명령ㆍ차례ㆍ함정ㆍ잰 수는 `10_Ai/12_문서양식/쓰는법.md` 「03_한글파일.py」 절이 정본이다. 지금 어디까지 되는지도 그 절 맨 위 표에 있다.

## 요청마다

도구는 `python 10_Ai/12_문서양식/system_도구/03_한글파일.py` 하나다.

| 요청 | 어디로 |
|---|---|
| 「이 한글 파일 검토해봐」 · 사용자가 고친 파일 읽기 | `--보기 "<hwpx>"` → 글은 `--찾기` · 모양은 `--pdf` 로 뽑아 쪽 그림으로 본다 |
| 글 몇 곳 고치기 | `--바꾸기 "<hwpx>" "<낼 hwpx>" "옛" "새"` — 0곳이면 글이 쪼개진 것이니 그 문단을 `글넣기` 로 |
| 문단 차례 다시 놓기 · 두 파일 합치기 | 도구의 함수(`열기`ㆍ`글넣기`ㆍ`번호맞춤`ㆍ`저장`)를 불러 그 문서에 맞춰 짠다 — 본보기 `99_기계/06_기록/작업기록/개포동1280_설계도서검토_261001/e27_건축주용2.py` |
| 화면(html)을 한글 파일로 새로 짓기 | 본보기 같은 폴더 `e25_hwpx.py`(python-hwpx · 한글 2018 판 번호로 낮추기 · 색은 뒤집어 적는다) |
| 지은 뒤 | `--검사 "<hwpx>"` 가 「✔ 탈 0」 → 탐색기로 가리킨다 → 한글에서 열어 보고 저장하는 것은 사용자가 한다 |
| 「PDF 만들어줘」 · 쪽 나눔 보기 | `--pdf "<hwpx>"` — 한글을 켜지 않는다 · ⚠ 가 찍히면 사용자가 아직 저장하지 않은 파일이니 저장을 부탁드린 뒤 다시 뽑는다 |

## 남에게 보낼 문서로 정리할 때 (건축주용 · 2026-10-08 개포동 1280 한 건에서 나온 꼴)

1. **받는 사람을 먼저 본다.** AI 가 지은 검토 화면(현황ㆍ검토ㆍ결론, 조문 상자, 색 표시)은 사용자가 보기 좋은 꼴이다. 그대로 보내지 않는다.
2. **앞은 결론, 뒤는 붙임.** 앞 = 머리(로고ㆍ수신ㆍ발신) → 왜 보내는지 → 요약 → 항목마다 결론 그림 한 장과 결론 글. 뒤 = 「붙임. 검토 근거」 로 현황ㆍ검토.
3. **사용자가 손으로 쓴 글은 그대로 둔다.** 나머지를 그 글에 맞춘다 — 말투(「합니다」) · 방 이름 · 결론의 방향. 결론이 갈리면 사용자가 쓴 쪽이 답이다.
4. **우리끼리 글을 뺀다.** 안쪽 문서 번호(「설계도서검토 10차 5-4절」) · 「(2026-10-01 정함)」 같은 날짜. 조문 인용 상자는 원문이라 말투를 바꾸지 않는다.
5. **같은 꼴의 다른 안**은 사용자가 고친 안의 손질(뺀 절ㆍ결론 문장)을 그대로 따른다. AI 가 새로 지은 요약 줄은 「사용자 확인 전」 으로 알린다.

⏸ 머리의 배치ㆍ글자 크기ㆍ표 크기는 아직 굳지 않았다 — `10_Ai/12_문서양식/문서양식.md` 「문서 기본양식」 줄(디자인 자료 정리 뒤).

## 꼭 아는 것 (값을 치른 것 · 풀이는 쓰는법)

- ★**한글 프로그램을 켜지 않는다.** 사용자가 같은 파일을 고치는 중일 수 있다. 꼭 필요하면 먼저 묻는다. 「파일 접근 허용」 보안 알림 창은 누르지 않는다. 사용자가 열어 둔 한글은 끄지 않는다.
- 원본을 덮어쓰지 않는다. 새 이름(시각까지)으로 내고, 새 판이 잘 나오면 내가 낸 앞 판만 휴지통으로 보낸다.
- 글이나 차례를 바꾼 문단은 줄 나눔 계산값을 지운다. 사용자가 한글에서 저장하면 다시 생긴다.
- 두 파일 사이로 문단을 옮기면 모양 번호가 어긋난다 — `번호맞춤`.
- ★**PDF 는 한글이 저장한 파일에만 믿는다.** 저장 전 파일은 표 자리와 쪽 수가 한글과 다르다. 그런 PDF 는 남에게 보낼 것으로 내지 않는다.
- ★**한글 2018 은 색을 뒤집어 읽는다**(파일의 `#FF0000` 이 화면에서는 파랑). 새로 짓는 글의 색은 뒤집어 적는다.
- PDF 프로그램은 `10_Ai/12_문서양식/system_도구/rhwp/`(받은 곳ㆍ지문ㆍ바꾸는 법은 그 폴더 `받은곳.md`). 실행 파일은 AI 가 받지 않는다 — 사용자가 받는다.
- 뽑은 PDF 는 한글이 뽑은 PDF 가 있으면 쪽 수 · 쪽마다 첫 글 · 글자 색 · 줄 자리로 맞대 본다. 사용자가 한 곳을 짚으면 그 까닭을 파일 속 값에서 찾는다.
