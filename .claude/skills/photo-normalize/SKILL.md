# 사진이 안 열리면 — `10_Ai/11_사진/`

> 상위 : `common-tools-map`
> 앞 : 사진이 든 폴더 (위 폴더여도 된다)
> 다음 : — (끝 · 사진의 ★내용을 읽는 일은 `drawing-analysis`)
> 넘기는 것 : 바꾼 것 N / N 장 · 다시 잰 것 0 장 · 탐색기로 연 폴더

자세한 것은 [`10_Ai/11_사진/쓰는법.md`](../../../10_Ai/11_사진/쓰는법.md) 에 있다. 여기는 **차례와 틀리기 쉬운 자리**만.

## 0 · 묻지 않고 바로 한다

> 📄 사용자 (2026-09-16) : *"속만 바꿔넣는것을 기본으로 세팅해줘 / 그러면 물어볼 필요없이 바로 진행되겠지?"*
> 📄 사용자 (2026-09-28) : *"아이폰에서 애플펜슬로 작성한 이미지들이 뭔가 안열림 … 이거는 항상 하는 반복작업이야"*

`CLAUDE.md` §2 표에서도 「사진 정상화 — 속만 바꿔 넣기」는 **혼자 정해도 되는 것**이다.
겉이름은 그대로, 원본은 그 폴더 아래 `원본_아이폰사진/` 으로 옮기므로 언제든 되돌릴 수 있다.

## 1 · 차례

```
① 사진이 든 폴더를 찾는다     도구는 ★한 단계만 본다 — 위 폴더를 받으면 아래 폴더까지 찾는다
② 폴더마다 --조회            「★바꿀 것 N 장」 을 센다 (안 바꾼다)
③ 폴더마다 바꾼다             기본 동작 · 원본은 원본_아이폰사진/
④ 잰다                      폴더마다 「★다시 잰 것 : 겉이름과 속이 다른 것 0 장」
                            + 바꾼 사진 하나를 그림으로 열어 ★펜 글씨가 살았나 본다
⑤ 끝나는 순간 탐색기          explorer.exe /select,"<바꾼 사진 하나>" — 사진은 띄우지 않는다
```

```bash
# ① ~ ③ — 위 폴더 하나로 아래 폴더까지 (배쉬 변수 이름은 ASCII · 경로는 따옴표)
top="02_프로젝트/<폴더>"
find "$top" -maxdepth 2 -type f \( -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.heic' -o -iname '*.heif' -o -iname '*.png' \) \
     -not -path '*/원본_아이폰사진/*' -printf '%h\n' | sort -u \
| while IFS= read -r dir; do python "10_Ai/11_사진/system_도구/01_사진정상화.py" --폴더 "$dir" --조회; done
# 바꿀 것이 있으면 같은 줄에서 --조회 를 빼고 한 번 더
```

`-maxdepth 2` 는 위 폴더와 그 바로 아래까지다. `G:` 는 구글 드라이브라 깊이 훑지 않는다(`CLAUDE.md` §5).

## 2 · 틀리기 쉬운 자리

**확장자를 믿지 않는다.** 겉이 `.JPG` 인데 속이 아이폰 사진(HEIF)인 것이 「안 열린다」의 진짜 원인이다.
겉이 `.HEIC` 인 것은 드물다 — 2026-09-16 수서동은 17장 중 1장, 2026-09-28 시대인재는 13장 중 0장이었다.

**애플펜슬로 표시한 사진이 탈난다** (2026-09-28 실측 두 번 · 시대인재 25장 중 13장 · 서초동 17장 중 15장 — 바꾼 28장이 전부 펜 표시였다. 그래도 늘 전수로 잰다).

```
바꾼 13 장    전부 2731x2048 · 속 아이폰 사진   ← 사진에 펜으로 치수ㆍ글씨를 쓴 것
그대로 12 장   전부 4032x3024 · 속 보통 사진     ← 찍은 그대로
```

펜으로 표시하면 그 사진만 아이폰 꼴로 다시 저장된다. 바꾼 뒤에도 **빨간 펜 글씨ㆍ치수선은 그대로 남는다** — 13 / 13 장을 눈으로 봤다.

**압축(zip)만 있고 안 풀렸으면** 푸는 것은 먼저 묻는다 — 폴더를 새로 만드는 일이다(`CLAUDE.md` §2).
**동영상(.MOV)은 안 본다** — 도구는 사진만 센다.

## 3 · 도구

```
python 10_Ai/11_사진/system_도구/01_사진정상화.py --폴더 "<폴더>" --조회     안 바꾸고 세기만
python 10_Ai/11_사진/system_도구/01_사진정상화.py --폴더 "<폴더>"            ★바꾼다 (기본)
python 10_Ai/11_사진/system_도구/01_사진정상화.py --폴더 "<폴더>" --옆에      제자리를 안 덮고 옆에 새 파일
python 10_Ai/11_사진/system_도구/01_사진정상화.py --자가검사                  파일 없이 도는 검사
```
