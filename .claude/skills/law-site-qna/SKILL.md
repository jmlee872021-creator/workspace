## 2 · 함정 (값을 치르고 얻은 것)

- **「그냥 질문에 대해서만 검토해줘」** — 검토 범위를 좁힌 말이다. Q 로 안 남긴다는 뜻이 아니다(2026-09-17 채팅으로만 두 번 답하고 다시 썼다).
- **갈래 이름은 폴더ㆍ원본의 말로 짧게.** 갈래가 하나면 PDF 이름이 `<갈래>검토_…` 가 된다 — 「집합건물 · 분할등기」로 지었다가 PDF 이름에 가운뎃점이 들어가 다시 뽑았다.
- **본문에서 다른 물음을 번호로 가리키지 않는다** — 「앞의 벽 물음」처럼 일반 문장으로 (쓰는법 Q67).
- **확인용 HTML 의 법령 원문은 접혀 나온다** (2026-10-09) — 조 이름과 「↳ 위의 …」 줄은 보이고 원문만 「원문 보기」 로 편다(`프로젝트.화면뽑기`).
- **그 법 아래 고시까지 연다** — 법ㆍ시행령ㆍ시행규칙 조문만 훑고 「규정이 없다」 고 하지 않는다. `법.db` 의 `행정규칙` 을 이름(그 법ㆍ그 업종 낱말)으로 찾아 별표까지 본다(2026-10-09 서초동 1361-10 — 관광호텔 식당 요건을 관광진흥법 조문에서만 찾다가 사용자 「관련 규정들이 명확하게 있을것 같은데 … 설명이 명확하지가 않아」 · 답은 문체부 고시 「호텔업 등급결정업무 위탁 및 등급결정에 관한 요령」 [별표 2] 식음료업장 필수 항목에 있었다).
- **창고에 없는 것은 ⏸ 로 곁에 적는다** — 대법원 판례ㆍ등기선례는 법.db 에 없다. 짐작으로 채우지 않는다.
- **해설은 곁의 「해설(원문 아님)」 자리에만** — 조문 문구를 읽어 낸 해석은 원문처럼 쓰지 않는다.
- 고르기에 **없는 이름표**를 대면 도구가 멈춘다 — `--보기` 로 이름표를 다시 본다.
- **대지 이름을 배쉬 변수에 담을 때는 영문 이름(`SITE=`)으로** — 한글 이름(`대지=`)은 그 줄만 실패하고 다음 명령이 「$대지」 글자 그대로 돈다. 별표크롭은 문답이 없는 대지 이름에도 폴더를 지어 `02_프로젝트/$대지/` 가 생겼다(2026-09-23) · 돌리기 전에 `test -d` 로 대지 폴더부터 잰다.
- **있는 Q 의 글을 고치기 전에 가장 새 PDF 의 강조를 본다** — 사용자는 PDF 를 읽으며 강조를 칠한다. 칠한 문장을 고치면 그 강조는 새 PDF 로 못 옮겨진다(2026-09-23 Q-003 결론 — 23개 중 22개 · 도구는 옛 PDF 를 남긴다). 고칠 문장에 강조가 있으면 고치기 전에 알린다.
- **법.db 에 없는 법(온천법 등)은 받은 XML 에서 곁으로** — 「그 낱말이 현행에 없다」면 옛 판 부칙까지 본다. 용원리 662 「온천지구」는 2001.1.26 부칙 ② 가 온천원보호지구로 본다고 정했다(`법령받기.py --옛법 … --날`).
- **yaml `답:` 칸에 「- 」 목록을 쓰면 목록 앞뒤에 빈 줄을 둔다** — 빈 줄 없이 문장 바로 밑에 쓰면 PDF 에서 목록이 앞 문단에 붙어 한 문단으로 찍힌다(2026-09-29 개포동 1280 Q-013~015 · 에러ㆍ인쇄 잣대 경고 없음 — 그림으로 봐서 잡았다). 넣은 뒤 그 Q 쪽을 한 장 그림으로 본다. 도구가 스스로 빈 줄을 넣게 할지는 안 정했다(01_일지 09-29).

```

- 부대시설의 위치ㆍ면적ㆍ종류가 바뀌면 30일 안에 변경등록을 한다(법 제4조 제4항, 시행령 제6조 제1항 제4호ㆍ제2항).
                                                    ← 요건ㆍ절차는 서술어로 맺은 문장 목록 (md 는 목록 앞뒤에 빈 줄)

[확인 필요] 증명 서류의 목록, 서초구가 등록심의에 올리는지.     ← 사용자ㆍ구청ㆍ도면이 채울 것
```

- **쓰지 않는 것** — 조문 번호와 화살표의 나열(「법 제4조 제3항 「…」 → 시행령 제5조 「…」」) · 조문 묶음에 붙인 이름(「갈래 1」) · 요건×근거×상태 표 · 판단(가능성ㆍ권고ㆍ「~로 보인다」ㆍ「구청이 물을 것」 — CLAUDE.md §1 「판단으로 앞서 가지 않는다」).
- **조문에 없으면 없다고 적는다** — 「…를 적은 글은 ○○법 제N조와 법제처 해석례에서 찾지 못했다」. 세어 본 범위(찾은 낱말ㆍ훑은 조문)를 곁에 남긴다.
- **행정 절차는 걸음마다 다섯 줄** — 받는 곳 · 내는 것 · 검토하는 것 · 이상이 없으면 · 이상이 있으면. 조문은 받는 곳을 「구청장」 으로만 적으니 부서 이름을 지어 넣지 않는다. 걸음 사이 앞뒤는 조문이 정한 것(「…하기 전에」ㆍ「…한 날부터 30일 이내」)만 차례로 쓰고 나머지는 「조문에 없다」.
- **조문 고리를 따라가는 물음** — 시작 조문에서 「대통령령으로 정하는」ㆍ「○○부령으로 정한다」 를 따라간다. 근거 칸에 `깊이:`ㆍ`받는글귀:` 를 적으면 화면에 「↳ 위의 「…」」 로 이어진다. 답 칸은 조문 차례가 아니라 위 꼴(뜻의 차례)로 쓴다.

- **사용자가 쓴 결론 초안을 볼 때** — 맞는 줄은 적지 않고 「초안 : … / 조문 : … / → 고칠 말」 로 고칠 곳과 빠진 것만. 사용자가 고쳐 저장한 글은 그대로 두고 나머지를 그 글에 맞춘다.
