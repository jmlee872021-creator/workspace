## 3 · 두 단 — **관문(걸리나) → 체크항목(맞나)**

```
1단 관문    이 법이 이 건에 **걸리기나 하는가**       예 → 2단 · 아니오 → 끝 · ⏸ → 멈춘다
2단 체크항목  걸린다면 **적합한가 / 대상인가**          원본 별표 2 의 체크 상자가 절대 기준
```

관문의 `재는법` 일곱 (수는 1 절 「지금 수」 · 지목ㆍ용도는 요건 안에서만) + 규칙에 얹는 칸 셋 `행위:` · `대지물음:` · `보일이름:`

    언제나     관문이 없다 — 모든 대지에 걸린다
    구역안     잣대 {구역들: [도시지역, 지구단위계획구역]}   ← 목록을 받는다 · 글자가 들어 있는지로 찾는다(이름 일부만 맞아도 걸린다 - 규칙 제안 가)
    지목       잣대 {지목: [임야]}
    자료에서   잣대 {변수: 연면적, **칸: 계획**, 연산: ">=", 문턱: 500}
               글자 값은 낱말로 {변수: 건축주, 칸: 계획, 연산: "==", 문턱: 공공, 낱말: [민간, 공공]} — 낱말 밖 글은 ⏸ (2026-09-30 Q3 ①)
    용도       잣대 {용도들: [공장]}                     층별 용도에서 찾는다
    사람에게   `관문답:` 에서 찾고 없으면 ⏸ → **`필요자료:` 를 반드시 적는다** (무엇을 보면 갈리나 - `관문.py --짓기` 가 N / N 을 찍는다)
    쪼개서     `요건:` 여럿을 하나씩 재고 묶는다 (`묶는법: 모두` 면 「그리고」 · 요건 안에 또 요건)
    행위:      재는법과 따로 — `행위: [신축, 증축]` · 설계개요 `계획.행위` 로 먼저 거르고 「그리고」로 얹는다 (못 알아본 글ㆍ섞인 리모델링은 ⏸)
    대지물음:  같은 물음이 여러 줄에 되풀이되면(실제로 농사짓는 땅ㆍ하천ㆍ철도 30m ㆍ장애물 제한표면ㆍ실제로 산지 …) 규칙ㆍ요건에 `대지물음: <이름>`
               → 사실.yaml `대지답: {<이름>: {답, 왜, 출처}}` 한 번으로 함께 닫힌다 · 줄의 `관문답` 이 먼저 (창고 쓰는법 「대지답」)
    보일이름:  구역안 규칙이 화면에 보일 구역 이름(토지이음 코드표 이름) · 판정은 잣대로만 한다

## 4 · 함정 (값을 치르고 얻은 것)

- ★**행위는 조문 글자로만 단다** — 「건축하는 경우」ㆍ「신축하는 것만」ㆍ「신축ㆍ증축」 · 건축법 제55ㆍ56조(건폐율ㆍ용적률)는 「건축하는」 이 없어 안 달았다(짐작했다가 원문에서 바로잡음) · 건축법 조는 제19조⑦ 준용 목록이면 용도변경도 넣는다 · 상자 「비대상」 이 그 행위를 받으면 관문에 안 단다(원본이 세는 칸을 안 바꾼다 · 창고 쓰는법 「행위」).
- ★★**⏸ 는 「사람이 판단할 일」이 아니다** — *"한국건축규정이라는것은 '체크'가 가능한 형태로 답이 나오는 알고리즘적인 요소로 답을 구할수가 무조건 있는거야."*
  ⇒ ⏸ 마다 무슨 서류를 떼면 닫히는지(`필요자료:`)를 댄다 · `관문.py --짓기` 가 「무엇을 보면 갈리는지 적힌 것 N / N」 을 찍는다.
- ★**「자동으로 못 잰다」는 까닭은 낡는다** — `쪼개서`ㆍ목록 잣대가 생기며 17 개가 자동이 됐다(2026-09-21) · 두 번째 검토도 「용도 재는법이 있으니 사람에게 → 자동」 을 셋 찾았다(규칙 제안 나).
- ⚠⚠ **`자료에서` 는 `칸:` 을 적는다** — 안 적으면 철거될 옛 건축물의 수로 새 건축물을 잰다(에러 없이 답만 틀린다) · 글자 칸(「지상 7층」)을 수로 견주지 않는다.
- ★★**「등」이 붙었다고 여는 쪽으로 읽지 않는다** — 상자가 호를 못박았으면 그 호만 센다(7-5(3) · 국토계획법 제76조⑤ 는 닫힌 목록).
- ⚠ **구역안은 글자 포함으로 찾는다** — 「자연공원」 은 도시자연공원구역에, 「공항」 은 공항소음구역에도 걸린다 · 반대로 토지이음이 세분 이름(「절대보호구역」)만 찍으면 못 잡는다(규칙 제안 가 24 곳) · 「…(접합)」ㆍ「…(접함)」 은 2026-09-28 부터 빼고 찾는다(닿기만 한 것 · 「(저촉)」 은 안).
- ⚠ **사람이 적어 둔 `관문답:` 을 버리지 않는다** — `사람에게` 를 자동으로 바꾸면 그 답이 갈 곳을 잃는다(`--재보기` 가 세어 내보인다).
- ⚠ **`⚠` 는 주의를 여는 표시다** — 글 안에서 딴 뜻으로 쓰면 문장이 반 토막 난다 · 표시를 가리킬 때는 「주의」 라는 말로.
