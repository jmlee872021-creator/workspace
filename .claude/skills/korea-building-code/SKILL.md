## 3 · 두 단 — **관문(걸리나) → 체크항목(맞나)**

```
1단 관문    이 법이 이 건에 **걸리기나 하는가**       예 → 2단 · 아니오 → 끝 · ⏸ → 멈춘다
2단 체크항목  걸린다면 **적합한가 / 대상인가**          원본 별표 2 의 체크 상자가 절대 기준
```

관문의 `재는법` 일곱 (수는 1 절 「지금 수」 · 지목ㆍ용도는 요건 안에서만) + 규칙에 얹는 칸 셋 `행위:` · `대지물음:` · `보일이름:`

    언제나     관문이 없다 — 모든 대지에 걸린다
    구역안     잣대 {구역들: [도시지역, 지구단위계획구역]}   ← 목록을 받는다 · 글자가 들어 있는지로 찾는다(이름 일부만 맞아도 걸린다 - 규칙 제안 가)
    지목       잣대 {지목: [임야]}
    자료에서   잣대 {변수: 연면적, **칸: 계획**, 연산: ">=", 문턱: 500}
               글자 값은 낱말로 {변수: 건축주, 칸: 계획, 연산: "==", 문턱: 공공, 낱말: [민간, 공공]} — 낱말 밖 글은 ⏸ (2026-09-30 Q3 ①)
    용도       잣대 {용도들: [공장]}                     층별 용도에서 찾는다
    사람에게   `관문답:` 에서 찾고 없으면 ⏸ → **`필요자료:` 를 반드시 적는다** (무엇을 보면 갈리나 - `관문.py --짓기` 가 N / N 을 찍는다)
    쪼개서     `요건:` 여럿을 하나씩 재고 묶는다 (`묶는법: 모두` 면 「그리고」 · 요건 안에 또 요건)
    행위:      재는법과 따로 — `행위: [신축, 증축]` · 설계개요 `계획.행위` 로 먼저 거르고 「그리고」로 얹는다 (못 알아본 글ㆍ섞인 리모델링은 ⏸)
    대지물음:  같은 물음이 여러 줄에 되풀이되면(실제로 농사짓는 땅ㆍ하천ㆍ철도 30m ㆍ장애물 제한표면ㆍ실제로 산지 …) 규칙ㆍ요건에 `대지물음: <이름>`
               → 사실.yaml `대지답: {<이름>: {답, 왜, 출처}}` 한 번으로 함께 닫힌다 · 줄의 `관문답` 이 먼저 (창고 쓰는법 「대지답」)
    보일이름:  구역안 규칙이 화면에 보일 구역 이름(토지이음 코드표 이름) · 판정은 잣대로만 한다
