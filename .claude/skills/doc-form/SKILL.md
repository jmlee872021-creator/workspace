# 문서 양식 — 세부항목으로 말하고, 편집기로 보고, 양식에 굳힌다

> 상위 : `doc-form-map`
> 앞 : 그 양식으로 지은 초안(md → PDF) · 사용자의 말(「표지 ② 로 하자」)
> 다음 : 그 양식을 짓는 일감 — 반영한 모양으로 다시 짓는다
> 넘기는 것 : 정본 「고른 모양」(`10_Ai/12_문서양식/data/세부항목.yaml`) · 샘플 PDF · 화면에서 저장한 모양ㆍ메모 · 고친 짓는 도구

> 📄 사용자 (2026-09-17) : *"문서 양식 핸들링하는부분을 별도로 관리할수 있겠지? 이건 중요하니까, 모든 문서들의 샘플을 하나씩 만들어서 관리할 예정인거야"*
> 정한 것 : Q83 ① 세부항목 + 번호 찍은 샘플 · Q85 ① 창고 · Q87 ① 겉모양 13항목은 화면 · 짜임은 메모 · Q88 ① md 는 본문 · PDF 는 인쇄용 · Q89 ① 법률검토 문답부터 · Q90 ① 이 스킬

**이 스킬은 입구만 둔다.** 규칙ㆍ절차ㆍ함정의 사본을 여기에 두지 않는다 — 고칠 때는 창고의 `CLAUDE.md` · `쓰는법.md` 를 고친다.

## 먼저 여는 것

1. `10_Ai/12_문서양식/CLAUDE.md` — 사용자가 정한 것 (만들어 가는 차례 · 말하는 법 · 한 곳 · 화면에서 꾸미기 · 보여 주기)
2. `10_Ai/12_문서양식/쓰는법.md` — 두 도구의 쓰는 법 · 초안을 지은 뒤 편집기로 여는 차례 · 「양식 반영해」 차례 · 함정 · ⏸
3. `10_Ai/12_문서양식/문서양식.md` — 어떤 양식이 있나 (이름 · 규칙 문서 · 짓는 명령 · 본보기)

## 요청마다

| 요청 | 어디로 |
|---|---|
| 「어떤 양식이 있어?」 · 「○○ 샘플 만들어줘」 | `10_Ai/12_문서양식/문서양식.md` → 그 양식의 규칙 문서 → 짓는 명령 → 본보기 |
| 「표지 ② 로 하자」 · 없는 모양을 말로 | `10_Ai/12_문서양식/문서양식_세부항목.md` · 정본 `10_Ai/12_문서양식/data/세부항목.yaml` 에 다음 번호 → `python 10_Ai/12_문서양식/system_도구/01_샘플찍기.py --표짓기` → `python 10_Ai/12_문서양식/system_도구/01_샘플찍기.py --샘플 --열기` |
| 「이 문서 양식편집기로 열어줘」 · 초안을 지은 뒤 | `10_Ai/12_문서양식/양식꾸미기_열기.bat` 뒤에 `--문서 "<대지>"` — 쓰는법 「AI 가 초안을 지은 뒤」 |
| 「양식 반영해」 | `python 10_Ai/12_문서양식/system_도구/02_꾸미기서버.py --메모목록` → 쓰는법 「양식 반영해 를 받으면」 |

## 잣대

- `python 10_Ai/12_문서양식/system_도구/01_샘플찍기.py --자가검사` — 정본ㆍ표ㆍ이름표ㆍ고른 모양
- `python 10_Ai/12_문서양식/system_도구/02_꾸미기서버.py --자가검사` — 칸 정본ㆍ문서 고르기ㆍ쪽 찾기ㆍ서버 실물
- 가이드ㆍ스킬을 고친 뒤 `python 가이드검사.py` — ⒅ 이 이 스킬과 지도가 이어졌나 잰다
