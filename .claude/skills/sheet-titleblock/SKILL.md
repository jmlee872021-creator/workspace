## 박스 크기 = ★A3(420 x 297) x A3배율 — 블록 이름이 곧 A3 축척이다

```
폭 = ★420 x A3배율   ( = 840 x A1배율 )        높이 = ★297 x A3배율   ( = 594 x A1배율 )
검산 : 폭 / (높이/297) 가 ★420 인가        가로세로 = ★1.4141  (840/594)
```

⚠⚠ **★841 로 잡으면 안 된다** (2026-09-11 사용자 지적 · 계산으로 확인).
  ISO A1 이 841 x 594 인 것은 맞다. 그런데 도곽은 **A1 종이를 그린 것이 아니라
  ★플롯 창**이고, 이 사무소는 **A3 로 출력**한다. 「용지에 맞춤」은 **가로비·세로비 중
  ★작은 쪽**을 쓰므로 —

```
창 841 x 594  →  A3(420x297) : 가로비 0.499405 < 세로비 0.500000  →  ★0.119% 작게 찍힌다
창 840 x 594  →  A3 : 가로 0.5 = 세로 0.5 ✔      A1(841x594) : 세로가 제한이라 1.0 ✔
                  ★A3 와 A1 양쪽 다 맞는 유일한 값이다
```

```
실측 (2026-09-11 · 개포동 655-4 · 폭 / A3배율)
   scale_150   63,000 / 150 = 420.00  ✔        scale_4 · _10 · _20 · _50 · _80
   scale_200   84,000 / 200 = 420.00  ✔        scale100_box · scale_120
   scale400   168,000 / 400 = 420.00  ✔          →  전부 ★420.50 (폭이 0.5mm 넓다)
```
★ **A3 축척 = A1 배율 x 2.** 도곽 머리의 큰 글자(`A3 1:100`)와 블록 이름이 그 값이다.
