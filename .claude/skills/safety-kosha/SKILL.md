## 2 · 차례 — **다섯 걸음**

```bash
# ① 찾는다 — 낱말이 실제로 나온 지침을 **세어서** 고른다. 내가 고르지 않는다
python 10_Ai/5_산업안전보건공단_kosha/_짓기/찾기.py --찾기 지붕
python 10_Ai/5_산업안전보건공단_kosha/_짓기/찾기.py --찾기 동바리 --분야 D
python 10_Ai/5_산업안전보건공단_kosha/_짓기/찾기.py --지침 C-59-2022        쪽별 머리
python 10_Ai/5_산업안전보건공단_kosha/_짓기/찾기.py --쪽 C-59-2022 15       ★ **원문 그대로**

# ②ㆍ법령도 함께 — 지침은 지침이고 **의무는 법에 있다**
python 10_Ai/1_법DB/찾기.py --조 "산업안전보건기준에 관한 규칙 제45조"

# ③ 보고서 md 를 쓴다  (또는 뽑기.py 로 뼈대를 뽑는다)
python 10_Ai/5_산업안전보건공단_kosha/_짓기/뽑기.py --공정 해체 --몇 20 --낼곳 "<md>"

# ④ 채점 — **인용이 원문 그대로인가**   ← 이게 없으면 인용이 아니라 기억이다
python 10_Ai/5_산업안전보건공단_kosha/_짓기/채점.py "<md>"

# ⑤ PDF 를 찍고, 인용한 원본만 모은다
python 10_Ai/5_산업안전보건공단_kosha/_짓기/보고서PDF.py "<md>"

```

⚠ **④를 건너뛰지 않는다.** 채점은 「바뀐 글자」를 잡는다 —
  2026-09-04 검토에서 처음에 **인용 3개가 「재지 못하고 지나친 줄」**로 빠졌다.
  `> **6.3(3)(바)** …` 처럼 **괄호가 두 겹이면 안 재어진다.** 안 재는 인용은 없는 것과 같다.
  ⚠⚠ 더 나쁜 쪽은 **괄호가 한 겹**(`> **6.3(3)** …`)일 때다 — 이건 **앞 인용의
    지침번호를 물려받아** 재어진다. 앞이 C-59 인데 D-C-9 본문을 번호 없이 적으면
    **엉뚱한 지침에 대고 재어 거짓 어긋남**이 난다.
  ⇒ 결론은 같다 — **늘 지침번호를 붙여 적는다.**
  ⇒ 인용은 늘 **`> **C-59-2022 6.3(3)(바)** 본문…`** 꼴로 적는다.

⚠ **md 를 고쳤으면 ⑤를 다시 돌린다.** 안 그러면 md 와 PDF 가 갈린다.

## 4 · ⚠ 값을 치르고 안 것

① **번호 앞글자로 분야를 가르면 틀린다** — 옛 꼴 `A-<숫자>-<연도>` **148건**은
   전부 **보건·위생(E)** 다. 그런데 `A-%` 로 넓게 세면 171건이고 새 꼴
   `A-G-*`ㆍ`A-R-*` **23건은 산업안전일반(A)** 이다.
   분야는 `지침.분야` 칸으로만 가른다

② **0건이 「없다」가 아니다** — 이 창고는 **973건뿐**이고 못 받은 것이 넷ㆍ스캔본이 하나다.
   「샌드위치패널」은 창고에 **1건**뿐이었다 (⑴ 원본이 원래 그렇다)

③ **화면에는 `내용`만** 쓴다. `민내용` 은 검색용이다

④ 채점은 **바뀐 글자만** 잡는다 — 앞뒤를 잘라 뜻이 바뀐 인용은 **못 잡는다.**
   못 재는 것은 못 잰다고 적는다

⑤ **`찾기.py` 는 낱말이 나온 쪽 번호를 안 찍는다** (2026-09-18) — 지침 이름과 「쪽 수」만 센다.
   원문을 인용하려면 후보 지침을 `--지침` 으로 열어 쪽 수를 보고 `--쪽` 으로 **1쪽부터 훑어**
   낱말이 든 쪽을 고른다. 고른 쪽 수를 `--찾기` 의 쪽 수와 **맞대 본다**
   (「아웃트리거」 7건 — 훑어 고른 쪽 수가 7/7 같았다)

⑥ **절 번호는 앞 쪽에 있다** — 쪽이 바뀌는 자리에서 문장이 잘린다
   (C-74-2015 6.3(4)는 10쪽 끝에서 11쪽으로 이어진다). 인용 앞에 붙일 번호를 맞추려면
   **앞 쪽을 함께 읽는다.** <별표>ㆍ<부록>도 제목이 앞 쪽에 있다

⑦ **창고 밖 값은 원문 표를 열어 확인한다** — 웹 검색 요약의 수를 그대로 쓰지 않는다.
   2026-09-18 각파이프 □50×50×2.3t 은 규격표 쪽을 열어 **3.34 kg/m** 를 보고,
   단면 계산(3.44 kg/m)으로 한 번 더 맞댔다(차이는 모서리 둥글기).
   ⚠ 사다리차 운반구 크기ㆍ적재하중은 **웹에 출처 있는 제원이 없었다** — 장비 업체 제원표를 받는다

⑧ **계획서에 실린 제원표도 의심한다** — 쌍문동 32쪽 「제원표 - 사다리차」에 실린 것이
   버켓ㆍ「정격하중 최대 300kg(작업자+공구)」인 **스카이(고소작업대) 제원**이었다.
   장비 이름이 아니라 **표의 칸**을 보고 무슨 장비인지 가린다

## 5 · 답에 반드시 넣을 것

- **못 한 것을 세 갈래로** — ⑴ 원본이 원래 그렇다 ⑵ 우리가 아직 안 가졌다 ⑶ 우리 결함
